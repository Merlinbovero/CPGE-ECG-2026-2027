Formulaire / Mémo — tout le programme d'italien en un écran par fiche

Les 5 fiches de révision condensées, regroupées ici pour une relecture rapide avant une khôlle ou un DS.

1. Civilisation italienne
  • Dates clés : 1861 (unité), 1922 (Mussolini), 1946 (République), 1948 (Constitution), 1992 (Mani pulite, Falcone/Borsellino), 2022 (Meloni).
  • Questione meridionale : PIB/hab. Sud ≈ 55-60 % du Centre-Nord. Dette ≈ 135-140 % du PIB.
  • Mafias : Cosa Nostra, Camorra, 'Ndrangheta. Hiver démographique : ≈ 1,2 enfant/femme.
2. Grammaire
  • Essere/avere : mouvement, pronominaux, piacere → essere + accord.
  • Imperfetto (arrière-plan) vs passato prossimo (événement ponctuel) vs passato remoto (récit historique).
  • Credo che + subjonctif (≠ français) ; jamais de conditionnel après se ; futur après quando/se.
  • Periodo ipotetico : réalité / irréel présent (subj. imparfait → cond. présent) / irréel passé.
3. Vocabulaire de presse
  • Verbes : affermare, sostenere, sottolineare, ribadire, denunciare, auspicare.
  • Augmenter/diminuer : impennarsi, crollare, dimezzarsi, raddoppiare.
  • Faux amis : fermare (arrêter), salire (monter), sentire (entendre), la gente (singulier).
4. Méthodologie
  • Version : repérer les temps italiens et choisir l'équivalent français.
  • Thème : repérer le point de grammaire testé ; sécuriser essere/avere, doubles consonnes, accents.
  • Khôlle : riassunto (3-4 min) → commento (4-5 min) → colloquio.
