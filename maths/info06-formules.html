Informatique I6. Traduire les mathématiques en Python

L'objectif de fin de première année : savoir écrire un petit programme et surtout traduire une formule mathématique en code. Une somme \(\sum\) devient une boucle, un produit \(\prod\) aussi, une suite récurrente devient une mise à jour de variable. Cette fiche fait le pont entre la notation mathématique et Python.

TP tout au long de l'année
Objectifs de la fiche
  • Traduire une somme \(\sum\) et un produit \(\prod\) en boucle avec accumulateur.
  • Coder factorielle, coefficient binomial, suites (récurrentes d'ordre 1 et 2).
  • Utiliser le module math (racine, exponentielle, logarithme, \(\pi\)…).
  • Évaluer une fonction ou un polynôme, gérer les formules par morceaux.
  • Structurer un petit programme complet (données → traitement → résultat) avec des fonctions.

1. Le module math

Pour les fonctions mathématiques usuelles, on importe le module math :

import math

math.sqrt(2)     # racine carrée : 1.4142135623730951
math.exp(1)      # e^1 : 2.718281828459045
math.log(math.e) # logarithme népérien : 1.0
math.log(8, 2)   # logarithme en base 2 : 3.0
math.factorial(5)# 120
math.comb(5, 2)  # coefficient binomial C(5,2) : 10
math.floor(3.7)  # partie entière inférieure : 3
math.pi, math.e  # constantes 3.14159..., 2.71828...

On peut aussi écrire la racine sans math : x ** 0.5. Mais math.sqrt est plus lisible.

2. Traduire une somme

Méthode — de \(\sum\) à la boucle

La somme \(\displaystyle S = \sum_{k=1}^{n} f(k)\) se code en trois temps : initialiser l'accumulateur à 0, parcourir les indices, ajouter chaque terme.

# S = somme pour k de 1 à n de k**2
S = 0
for k in range(1, n + 1):   # attention : n+1 pour inclure n
    S += k**2

Le squelette est toujours le même : seul change le terme f(k) ajouté. Pour une somme de \(0\) à \(n\) : range(n + 1).

⚠️ Les deux erreurs classiques
  • La borne : range(1, n) s'arrête à \(n-1\). Pour aller jusqu'à \(n\), écrire range(1, n + 1).
  • L'oubli de l'initialisation : toujours S = 0 (somme) ou P = 1 (produit) avant la boucle.

3. Produit, factorielle, binôme

# Produit : P = produit pour k de 1 à n de f(k)  ->  init à 1
def factorielle(n):
    P = 1
    for k in range(1, n + 1):
        P *= k
    return P                       # factorielle(5) = 120

# Coefficient binomial C(n,k) = n! / (k!(n-k)!)
def binomial(n, k):
    return factorielle(n) // (factorielle(k) * factorielle(n - k))

On utilise la division entière // car un coefficient binomial est un entier.

4. Traduire une suite

Ordre 1 \(u_{n+1} = f(u_n)\) : une seule variable, mise à jour \(n\) fois.

def u(n):          # u_0 = 3, u_{k+1} = 2 u_k - 1
    x = 3
    for k in range(n):
        x = 2*x - 1
    return x

Ordre 2 \(u_{n+2} = a\,u_{n+1} + b\,u_n\) : deux variables mises à jour simultanément.

def fibo(n):       # F_0 = 0, F_1 = 1, F_{n+2} = F_{n+1} + F_n
    a, b = 0, 1
    for k in range(n):
        a, b = b, a + b     # affectation simultanée !
    return a

5. Évaluer une fonction ou un polynôme

Un polynôme \(P(x) = \sum_{i=0}^{d} a_i x^i\) donné par la liste de ses coefficients [a0, a1, …, ad] :

def eval_poly(coeffs, x):
    S = 0
    for i, a in enumerate(coeffs):   # i = indice, a = coefficient
        S += a * x**i
    return S
# eval_poly([3, -2, 0, 1], 2) = 3 - 4 + 0 + 8 = 7
Formules par morceaux

Une fonction définie par cas se traduit avec des if :

def f(x):
    if x < 0:
        return -x        # |x| pour x négatif
    else:
        return x**2      # x² sinon

6. Écrire un petit programme complet

La structure : données → traitement → résultat

Un petit programme s'organise en fonctions, chacune faisant une chose, et un enchaînement qui les appelle. Exemple : calculer la moyenne et la mention d'un élève.

def moyenne(notes):
    return sum(notes) / len(notes)

def mention(m):
    if m >= 16: return "TB"
    elif m >= 14: return "B"
    elif m >= 12: return "AB"
    elif m >= 10: return "passable"
    else: return "refusé"

def bulletin(notes):
    m = moyenne(notes)
    return m, mention(m)

# utilisation
print(bulletin([12, 8, 15, 11]))   # (11.5, 'passable')

Chaque fonction return son résultat ; on les compose. C'est le socle de tout programme, du plus petit exercice au sujet de concours.

Fiche de révision condensée
  • Somme \(\sum_{k=1}^n f(k)\) : S = 0 ; for k in range(1, n+1): S += f(k).
  • Produit / factorielle : P = 1 ; for k in range(1, n+1): P *= k.
  • Binôme : math.comb(n, k) ou fact(n)//(fact(k)*fact(n-k)).
  • Suite ordre 1 : x = u0 ; for k in range(n): x = f(x).
  • Suite ordre 2 : a, b = u0, u1 ; for k in range(n): a, b = b, a*... + b*....
  • Module math : sqrt, exp, log, factorial, comb, floor, pi, e.
  • Polynôme : for i, a in enumerate(coeffs): S += a*x**i.
  • Programme : découper en fonctions qui return, puis les composer.
  • S'entraîner : le jeu Python (70 niveaux) fait pratiquer tout ceci en exécutant ton code.

Exercices corrigés

Exercice 1 — Somme des inverses

Application directe

Traduire en Python la somme \(H_n = \displaystyle\sum_{k=1}^{n} \frac1k\). Écrire harmonique(n).

def harmonique(n):
    S = 0
    for k in range(1, n + 1):
        S += 1 / k          # 1/k pour un flottant
    return S                # harmonique(3) = 1.8333...

Exercice 2 — Somme d'une géométrique

Application directe

Écrire somme_geom(q, n) = \(\displaystyle\sum_{k=0}^{n} q^k\), puis prédire somme_geom(2, 3).

def somme_geom(q, n):
    S = 0
    for k in range(n + 1):   # de 0 à n
        S += q**k
    return S

somme_geom(2, 3) \(= 2^0 + 2^1 + 2^2 + 2^3 = 1 + 2 + 4 + 8 = 15\).

Exercice 3 — Le module math

Application directe

Que valent math.sqrt(16), math.factorial(4), math.comb(6, 2), math.floor(2.9) ?

math.sqrt(16) = 4.0 ; math.factorial(4) = 24 ; math.comb(6, 2) = 15 ; math.floor(2.9) = 2.

Exercice 4 — Produit

Application directe

Écrire produit(n) = \(\displaystyle\prod_{k=1}^{n}(2k)\) (produit des \(n\) premiers pairs). Prédire produit(3).

def produit(n):
    P = 1
    for k in range(1, n + 1):
        P *= 2 * k
    return P

produit(3) \(= 2 \times 4 \times 6 = 48\).

Exercice 5 — Somme des carrés

Application directe

Écrire somme_carres(n) = \(\displaystyle\sum_{k=1}^{n} k^2\), et vérifier avec la formule \(\frac{n(n+1)(2n+1)}{6}\) pour \(n = 3\).

def somme_carres(n):
    S = 0
    for k in range(1, n + 1):
        S += k**2
    return S                # somme_carres(3) = 14

Formule : \(\frac{3 \times 4 \times 7}{6} = \frac{84}{6} = 14\) ✓.

Exercice 6 — Double somme

Entraînement

Traduire \(\displaystyle\sum_{i=1}^{n}\sum_{j=1}^{n} (i \times j)\). Écrire double_somme(n) et prédire double_somme(2).

def double_somme(n):
    S = 0
    for i in range(1, n + 1):
        for j in range(1, n + 1):
            S += i * j
    return S

double_somme(2) : \(1{\cdot}1 + 1{\cdot}2 + 2{\cdot}1 + 2{\cdot}2 = 1+2+2+4 = 9\). (On reconnaît \((\sum i)^2 = 3^2 = 9\).)

Exercice 7 — Factorielle sans math

Entraînement

Recoder factorielle(n) avec une boucle (sans math.factorial). Prédire factorielle(0).

def factorielle(n):
    P = 1
    for k in range(1, n + 1):
        P *= k
    return P

factorielle(0) = 1 : la boucle range(1, 1) est vide, P reste à son initialisation 1 (produit vide).

Exercice 8 — Coefficient binomial

Entraînement

Écrire binomial(n, k) \(= \binom nk\) à l'aide d'une factorielle. Prédire binomial(5, 2).

def fact(m):
    P = 1
    for i in range(1, m + 1):
        P *= i
    return P

def binomial(n, k):
    return fact(n) // (fact(k) * fact(n - k))

binomial(5, 2) \(= \frac{120}{2 \times 6} = 10\). (Ou directement math.comb(5, 2).)

Exercice 9 — Suite récurrente

Entraînement

Soit \(u_0 = 1\), \(u_{k+1} = \frac12 u_k + 3\). Écrire u(n) et prédire u(2).

def u(n):
    x = 1
    for k in range(n):
        x = 0.5 * x + 3
    return x

u(0) = 1 ; u(1) = 3.5 ; u(2) = \(0.5 \times 3.5 + 3 = 4.75\).

Exercice 10 — Suite d'ordre 2

Entraînement

Soit \(v_0 = 2\), \(v_1 = 3\), \(v_{n+2} = 2v_{n+1} - v_n\). Écrire v(n) et prédire v(3).

def v(n):
    a, b = 2, 3
    for k in range(n):
        a, b = b, 2*b - a
    return a

Suite : \(v_0=2, v_1=3, v_2=4, v_3=5\) (c'est \(v_n = n+2\)). v(3) = 5.

Exercice 11 — Évaluer un polynôme

Entraînement

Écrire eval_poly(coeffs, x) = \(\sum_i a_i x^i\). Prédire eval_poly([1, 2, 3], 2).

def eval_poly(coeffs, x):
    S = 0
    for i, a in enumerate(coeffs):
        S += a * x**i
    return S

eval_poly([1, 2, 3], 2) \(= 1 + 2\times2 + 3\times4 = 1 + 4 + 12 = 17\).

Exercice 12 — Fonction par morceaux

Entraînement

Coder \(f(x) = \begin{cases} x^2 & \text{si } x \geqslant 0 \\ -x & \text{si } x < 0 \end{cases}\). Prédire f(-3) et f(4).

def f(x):
    if x >= 0:
        return x**2
    else:
        return -x

f(-3) = 3 (car \(-(-3)\)) ; f(4) = 16.

Exercice 13 — Série exponentielle

Approfondissement

Écrire exp_approx(x, n) = \(\sum_{k=0}^{n} \frac{x^k}{k!}\), en mettant à jour la factorielle au fil de la boucle (sans la recalculer).

def exp_approx(x, n):
    S = 1.0        # terme k = 0 : x^0/0! = 1
    fact = 1
    for k in range(1, n + 1):
        fact *= k          # fact vaut k!
        S += x**k / fact
    return S               # exp_approx(1, 20) ≈ 2.71828 (≈ e)

Astuce d'efficacité : on n'appelle pas une factorielle à chaque tour, on la construit progressivement.

Exercice 14 — Méthode de Horner

Approfondissement

Évaluer \(P(x) = a_0 + a_1 x + \dots + a_d x^d\) par le schéma de Horner \(P(x) = a_0 + x(a_1 + x(a_2 + \dots))\), qui évite de recalculer les puissances. Écrire horner(coeffs, x).

def horner(coeffs, x):
    S = 0
    for a in reversed(coeffs):   # du coefficient de plus haut degré au plus bas
        S = S * x + a
    return S
# horner([3, -2, 0, 1], 2) = 7  (même résultat que eval_poly, mais moins de multiplications)

Horner ne fait que \(d\) multiplications et \(d\) additions, contre \(\mathcal O(d^2)\) pour le calcul naïf des puissances.

Exercice 15 — Produit de deux sommes

Approfondissement

Calculer \(\left(\sum_{k=1}^{n} k\right)\left(\sum_{k=1}^{n} \frac1k\right)\). Écrire produit_sommes(n).

def produit_sommes(n):
    A = 0
    B = 0
    for k in range(1, n + 1):
        A += k
        B += 1 / k
    return A * B

On calcule les deux sommes dans une seule boucle, puis on multiplie les résultats.

Exercice 16 — Moyenne et variance

Approfondissement

Écrire moyenne_variance(L) qui renvoie le couple \((\bar x, s^2)\) d'une liste, avec \(s^2 = \frac1n\sum x_i^2 - \bar x^2\).

def moyenne_variance(L):
    n = len(L)
    m = sum(L) / n
    m2 = sum(x*x for x in L) / n
    return m, m2 - m*m
# moyenne_variance([2, 4, 4, 6, 9]) = (5.0, 5.6)

Une fonction peut renvoyer plusieurs valeurs (un couple). On applique Kœnig-Huygens.

Exercice 17 — Petit programme : le change

Approfondissement

Écrire un programme convertir(euros, taux) qui convertit un montant en euros vers une autre devise (multiplication par le taux), arrondi à 2 décimales. Prédire convertir(100, 1.08).

def convertir(euros, taux):
    return round(euros * taux, 2)
# convertir(100, 1.08) = 108.0

round(x, 2) arrondit à 2 décimales — utile pour un montant.

Exercice 18 — Petit programme : le maximum et sa position

Approfondissement

Écrire meilleur(notes) qui renvoie le couple (meilleure note, position de l'élève) — la position est l'indice + 1.

def meilleur(notes):
    m, pos = notes[0], 0
    for i in range(1, len(notes)):
        if notes[i] > m:
            m, pos = notes[i], i
    return m, pos + 1
# meilleur([12, 18, 9, 15]) = (18, 2)

Exercice 19 — Somme conditionnelle

Approfondissement

Écrire somme_multiples(n) = somme des entiers de 1 à \(n\) qui sont multiples de 3 ou de 5. Prédire somme_multiples(10).

def somme_multiples(n):
    S = 0
    for k in range(1, n + 1):
        if k % 3 == 0 or k % 5 == 0:
            S += k
    return S

somme_multiples(10) : 3 + 5 + 6 + 9 + 10 = 33.

Exercice 20 — Synthèse : un mini-programme complet

Approfondissement

Un professeur veut, à partir d'une liste de notes : la moyenne, le nombre d'admis (≥ 10), et la mention de la moyenne. Écrire trois fonctions, puis rapport(notes) qui renvoie le triplet.

def moyenne(notes):
    return sum(notes) / len(notes)

def nb_admis(notes):
    c = 0
    for x in notes:
        if x >= 10:
            c += 1
    return c

def mention(m):
    if m >= 16: return "TB"
    elif m >= 14: return "B"
    elif m >= 12: return "AB"
    elif m >= 10: return "passable"
    else: return "refusé"

def rapport(notes):
    m = moyenne(notes)
    return m, nb_admis(notes), mention(m)
# rapport([12, 8, 15, 11]) = (11.5, 3, 'passable')

C'est la démarche complète : découper le problème en fonctions courtes qui return, puis les composer dans une fonction de synthèse. Prolonge avec le jeu Python.
