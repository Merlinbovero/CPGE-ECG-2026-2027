Informatique I4. Simulation d'expériences aléatoires et méthode de Monte-Carlo

Simuler, c'est faire répéter une expérience aléatoire des milliers de fois par la machine pour estimer une probabilité ou une espérance par des fréquences. C'est la partie de l'informatique la plus présente aux concours, en lien direct avec les chapitres de probabilités.

Méthode — Le schéma universel de simulation 
def frequence(N):

        # --- simuler UNE expérience ---
        # --- si l'événement est réalisé : ---

Trois ingrédients : la boucle des \(N\) répétitions, la simulation d'une expérience, le compteur. À \(N\) grand, la fréquence renvoyée approche la probabilité (loi des grands nombres).

2. Estimer une probabilité par une fréquence

Exemple complet — probabilité d'obtenir au moins un 6 en 4 lancers de dé (valeur exacte \(1 - (5/6)^4 \approx 0{,}518\)) :

import random as rd

def freq_au_moins_un_six(N):
    c = 0
    for k in range(N):
        succes = False
        for lancer in range(4):
            if rd.randint(1, 6) == 6:
                succes = True
        if succes:
            c += 1
    return c / N

print(freq_au_moins_un_six(100000))   # affiche environ 0.5177 (varie à chaque exécution)

La sortie fluctue autour de la valeur théorique : c'est normal, et les sujets demandent souvent de commenter cet écart (il diminue en \(1/\sqrt N\)).

3. Simuler les lois usuelles

import random as rd

def simule_binomiale(n, p):
    """Nombre de succès parmi n épreuves de Bernoulli(p)."""
    X = 0
    for k in range(n):
        if rd.random() < p:
            X += 1
    return X

def simule_geometrique(p):
    """Rang du premier succès (loi géométrique)."""
    X = 1
    while rd.random() >= p:      # tant qu'échec
        X += 1
    return X

def simule_uniforme(n):
    return rd.randint(1, n)

Pour valider : simuler 10 000 valeurs, comparer moyenne empirique et espérance théorique (\(np\), \(\frac1p\), \(\frac{n+1}{2}\)), tracer l'histogramme et le comparer au diagramme de la loi.

4. La méthode de Monte-Carlo

Principe

La méthode de Monte-Carlo estime une quantité déterministe (probabilité, espérance, intégrale, aire) par la moyenne d'un grand nombre de tirages aléatoires. Justification : la loi des grands nombres — la moyenne empirique de \(N\) répétitions indépendantes converge vers l'espérance.

Exemple 1 — estimer une intégrale. Si \(U\) est uniforme sur \([0,1]\), alors \(E\big(f(U)\big) = \int_0^1 f(t)\,\mathrm{d}t\) :

import random as rd

def monte_carlo_integrale(N):
    S = 0
    for k in range(N):
        u = rd.random()
        S += u**2            # ici f(t) = t²
    return S / N

print(monte_carlo_integrale(100000))   # environ 0.333  (valeur exacte : 1/3)

Exemple 2 — estimer \(\pi\) (aire du quart de disque). On tire des points uniformes dans le carré \([0,1]^2\) ; la proportion tombant dans le quart de disque \(x^2 + y^2 \leqslant 1\) approche son aire \(\frac\pi4\) :

def estime_pi(N):
    c = 0
    for k in range(N):
        x, y = rd.random(), rd.random()
        if x**2 + y**2 <= 1:
            c += 1
    return 4 * c / N          # estime_pi(1000000) donne environ 3.1418

Exercices corrigés

Exercice 1 — Lire une simulation

Application directe

Que calcule la fonction suivante ? Vers quelle valeur théorique la sortie se stabilise-t-elle quand \(N\) grandit ?

import random as rd
def f(N):
    c = 0
    for k in range(N):
        if rd.randint(1, 6) + rd.randint(1, 6) == 7:
            c += 1
    return c / N

Elle estime la probabilité d'obtenir une somme de 7 avec deux dés. Valeur théorique : \(\frac{6}{36} = \frac16 \approx 0{,}167\) (chapitre 10, exercice 1). La sortie se stabilise autour de 0,1667.

Exercice 2 — Écrire une simulation simple

Application directe

Écrire une fonction qui estime la probabilité qu'une main de 2 cartes tirées (sans remise) d'un jeu de 32 contienne au moins un as. Donner la valeur exacte attendue.

import random as rd

def freq_as(N):
    jeu = list(range(32))     # 0, 1, 2, 3 codent les quatre as
    c = 0
    for k in range(N):
        main = rd.sample(jeu, 2)      # 2 cartes distinctes
        if main[0] < 4 or main[1] < 4:
            c += 1
    return c / N

Valeur exacte : \(1 - \dfrac{\binom{28}{2}}{\binom{32}{2}} = 1 - \dfrac{378}{496} = \dfrac{118}{496} \approx 0{,}238\).

rd.sample(L, k) tire \(k\) éléments distincts — l'outil naturel des tirages sans remise.

Exercice 3 — Valider la loi géométrique

Entraînement

En utilisant simule_geometrique(p) du cours, écrire un programme qui estime \(E(X)\) pour \(p = 0{,}2\) à partir de 10 000 simulations. Quelle valeur attend-on ?

import random as rd

def simule_geometrique(p):
    X = 1
    while rd.random() >= p:
        X += 1
    return X

S = 0
for k in range(10000):
    S += simule_geometrique(0.2)
print(S / 10000)

L'espérance théorique est \(\frac1p = 5\) (chapitre 14) : la sortie fluctue autour de 5.0 (typiquement entre 4,9 et 5,1).

import random as rd

La simulation confirme la valeur théorique \(\approx 2{,}4\) % obtenue par la somme binomiale.

Exercice 5 — Monte-Carlo pour une intégrale (type concours)

Approfondissement

1. Justifier que si \(U\) est uniforme sur \([0,1]\), alors \(E(\mathrm{e}^{-U^2})= \int_0^1 \mathrm{e}^{-t^2}\mathrm{d}t\), et écrire la fonction Monte-Carlo correspondante.
2. L'intégrale vaut environ 0,7468. Donner un encadrement grossier a priori pour contrôler la sortie.

1. C'est le théorème de transfert version continue (admis en ECG1 sous cette forme : la moyenne des \(f(u_k)\) pour des \(u_k\) uniformes approche \(\int_0^1 f\)).

import random as rd

def mc(N):
    S = 0
    for k in range(N):
        u = rd.random()
        S += 2.718281828 ** (-u * u)    # ou : import math ; math.exp(-u*u)
    return S / N

2. Sur \([0,1]\), \(t^2 \in [0,1]\) donc \(\mathrm{e}^{-1} \leqslant \mathrm{e}^{-t^2} \leqslant 1\) : l'intégrale est entre \(0{,}368\) et \(1\). Une sortie hors de cet intervalle signalerait un bug. (Avec \(N = 10^5\), la sortie est typiquement 0,745 – 0,749.)

Exercice 6 — Le problème des anniversaires, version simulation (type concours)

Approfondissement

Écrire une fonction freq_coincidence(n, N) qui estime, sur \(N\) simulations, la probabilité qu'au moins deux personnes parmi \(n\) partagent leur anniversaire (365 jours équiprobables). Que doit-elle renvoyer pour \(n = 23\) (cf. chapitre 10, exercice 8) ?

import random as rd

def freq_coincidence(n, N):
    c = 0
    for k in range(N):
        jours = [rd.randint(1, 365) for i in range(n)]
        # coïncidence ssi la liste contient un doublon :
        if len(set(jours)) < n:
            c += 1
    return c / N

Pour \(n = 23\), la valeur théorique est \(1 - q_{23} \approx 0{,}507\) : la fonction renvoie environ 0.507.

set(jours) supprime les doublons : comparer sa taille à \(n\) détecte une coïncidence. Sans set, on peut trier la liste et comparer les éléments consécutifs.
