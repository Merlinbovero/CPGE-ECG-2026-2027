Informatique I4. Simulation d'expériences aléatoires et méthode de Monte-Carlo

Simuler, c'est faire répéter une expérience aléatoire des milliers de fois par la machine pour estimer une probabilité ou une espérance par des fréquences. C'est la partie de l'informatique la plus présente aux concours, en lien direct avec les chapitres de probabilités.

TP au semestre 2 surtout
Objectifs de la fiche (programme officiel)
  • Simuler une expérience élémentaire (dé, pièce, Bernoulli) avec random.
  • Appliquer le schéma universel boucle + compteur pour estimer une probabilité par une fréquence.
  • Simuler les lois usuelles (binomiale, géométrique, uniforme) et valider par comparaison moyenne empirique / espérance.
  • Mettre en œuvre la méthode de Monte-Carlo (intégrale, aire, \(\pi\)) et la justifier par la loi des grands nombres.
  • Commenter la fluctuation des estimations (en \(1/\sqrt N\)).

1. Simuler une expérience élémentaire

import random as rd

de = rd.randint(1, 6)            # lancer de dé équilibré
piece = rd.random() < 0.5        # pile ou face (True = pile)
bernoulli = rd.random() < p      # succès avec probabilité p
Méthode — Le schéma universel de simulation 
def frequence(N):
    compteur = 0
    for k in range(N):
        # --- simuler UNE expérience ---
        # --- si l'événement est réalisé : ---
        #         compteur += 1
    return compteur / N

Trois ingrédients : la boucle des \(N\) répétitions, la simulation d'une expérience, le compteur. À \(N\) grand, la fréquence renvoyée approche la probabilité (loi des grands nombres).

2. Estimer une probabilité par une fréquence

Exemple complet — probabilité d'obtenir au moins un 6 en 4 lancers de dé (valeur exacte \(1 - (5/6)^4 \approx 0{,}518\)) :

import random as rd

def freq_au_moins_un_six(N):
    c = 0
    for k in range(N):
        succes = False
        for lancer in range(4):
            if rd.randint(1, 6) == 6:
                succes = True
        if succes:
            c += 1
    return c / N

print(freq_au_moins_un_six(100000))   # affiche environ 0.5177 (varie à chaque exécution)

La sortie fluctue autour de la valeur théorique : c'est normal, et les sujets demandent souvent de commenter cet écart (il diminue en \(1/\sqrt N\)).

3. Simuler les lois usuelles

import random as rd

def simule_binomiale(n, p):
    """Nombre de succès parmi n épreuves de Bernoulli(p)."""
    X = 0
    for k in range(n):
        if rd.random() < p:
            X += 1
    return X

def simule_geometrique(p):
    """Rang du premier succès (loi géométrique)."""
    X = 1
    while rd.random() >= p:      # tant qu'échec
        X += 1
    return X

def simule_uniforme(n):
    return rd.randint(1, n)

Pour valider : simuler 10 000 valeurs, comparer moyenne empirique et espérance théorique (\(np\), \(\frac1p\), \(\frac{n+1}{2}\)), tracer l'histogramme et le comparer au diagramme de la loi.

4. La méthode de Monte-Carlo

Principe

La méthode de Monte-Carlo estime une quantité déterministe (probabilité, espérance, intégrale, aire) par la moyenne d'un grand nombre de tirages aléatoires. Justification : la loi des grands nombres — la moyenne empirique de \(N\) répétitions indépendantes converge vers l'espérance.

Exemple 1 — estimer une intégrale. Si \(U\) est uniforme sur \([0,1]\), alors \(E\big(f(U)\big) = \int_0^1 f(t)\,\mathrm{d}t\) :

import random as rd

def monte_carlo_integrale(N):
    S = 0
    for k in range(N):
        u = rd.random()
        S += u**2            # ici f(t) = t²
    return S / N

print(monte_carlo_integrale(100000))   # environ 0.333  (valeur exacte : 1/3)

Exemple 2 — estimer \(\pi\) (aire du quart de disque). On tire des points uniformes dans le carré \([0,1]^2\) ; la proportion tombant dans le quart de disque \(x^2 + y^2 \leqslant 1\) approche son aire \(\frac\pi4\) :

def estime_pi(N):
    c = 0
    for k in range(N):
        x, y = rd.random(), rd.random()
        if x**2 + y**2 <= 1:
            c += 1
    return 4 * c / N          # estime_pi(1000000) donne environ 3.1418
⚠️ Pièges classiques
  • Réinitialiser le compteur/succès à chaque répétition : remettre succes = False (ou l'accumulateur) au début de la boucle des \(N\) répétitions, pas avant.
  • Bernoulli(p) : rd.random() < p renvoie True avec probabilité \(p\) (car rd.random() \(\in [0,1[\)) ; ne pas écrire <=.
  • Géométrique : initialiser X = 1 (premier essai) et incrémenter tant qu'échec ; la condition while rd.random() >= p code « échec ».
  • La sortie fluctue : une simulation ne redonne jamais deux fois le même résultat ; ne pas confondre estimation et valeur exacte. L'écart décroît en \(1/\sqrt N\).
  • Diviser par \(N\) (le nombre de répétitions) pour obtenir une fréquence, pas par autre chose.
  • Sans remise : utiliser rd.sample(L, k) (éléments distincts), pas k appels à rd.choice.
Fiche de révision condensée
  • Élémentaire : rd.randint(1,6) (dé), rd.random() < p (Bernoulli), rd.sample(L,k) (sans remise).
  • Schéma : c = 0 ; for k in range(N): (simuler ; si événement : c += 1) ; return c/N.
  • Binomiale : compter les succès de \(n\) Bernoulli. Géométrique : X = 1 ; while échec: X += 1.
  • Validation : comparer la moyenne empirique à \(np\), \(\frac1p\), \(\frac{n+1}{2}\)…
  • Monte-Carlo intégrale : \(\frac1N\sum f(u_k) \to \int_0^1 f\) (\(u_k\) uniformes).
  • Monte-Carlo \(\pi\) : proportion de points de \([0,1]^2\) dans le quart de disque \(\to \frac\pi4\).
  • Justification : loi des grands nombres ; erreur \(\sim 1/\sqrt N\).

Exercices corrigés

Exercice 1 — Lire une simulation

Application directe

Que calcule la fonction suivante ? Vers quelle valeur théorique la sortie se stabilise-t-elle quand \(N\) grandit ?

import random as rd
def f(N):
    c = 0
    for k in range(N):
        if rd.randint(1, 6) + rd.randint(1, 6) == 7:
            c += 1
    return c / N

Elle estime la probabilité d'obtenir une somme de 7 avec deux dés. Valeur théorique : \(\frac{6}{36} = \frac16 \approx 0{,}167\) (chapitre 10, exercice 1). La sortie se stabilise autour de 0,1667.

Exercice 2 — Écrire une simulation simple

Application directe

Écrire une fonction qui estime la probabilité qu'une main de 2 cartes tirées (sans remise) d'un jeu de 32 contienne au moins un as. Donner la valeur exacte attendue.

import random as rd

def freq_as(N):
    jeu = list(range(32))     # 0, 1, 2, 3 codent les quatre as
    c = 0
    for k in range(N):
        main = rd.sample(jeu, 2)      # 2 cartes distinctes
        if main[0] < 4 or main[1] < 4:
            c += 1
    return c / N

Valeur exacte : \(1 - \dfrac{\binom{28}{2}}{\binom{32}{2}} = 1 - \dfrac{378}{496} = \dfrac{118}{496} \approx 0{,}238\).

rd.sample(L, k) tire \(k\) éléments distincts — l'outil naturel des tirages sans remise.

Exercice 3 — Valider la loi géométrique

Entraînement

En utilisant simule_geometrique(p) du cours, écrire un programme qui estime \(E(X)\) pour \(p = 0{,}2\) à partir de 10 000 simulations. Quelle valeur attend-on ?

import random as rd

def simule_geometrique(p):
    X = 1
    while rd.random() >= p:
        X += 1
    return X

S = 0
for k in range(10000):
    S += simule_geometrique(0.2)
print(S / 10000)

L'espérance théorique est \(\frac1p = 5\) (chapitre 14) : la sortie fluctue autour de 5.0 (typiquement entre 4,9 et 5,1).

Exercice 5 — Monte-Carlo pour une intégrale (type concours)

Approfondissement

1. Justifier que si \(U\) est uniforme sur \([0,1]\), alors \(E(\mathrm{e}^{-U^2})= \int_0^1 \mathrm{e}^{-t^2}\mathrm{d}t\), et écrire la fonction Monte-Carlo correspondante.
2. L'intégrale vaut environ 0,7468. Donner un encadrement grossier a priori pour contrôler la sortie.

1. C'est le théorème de transfert version continue (admis en ECG1 sous cette forme : la moyenne des \(f(u_k)\) pour des \(u_k\) uniformes approche \(\int_0^1 f\)).

import random as rd

def mc(N):
    S = 0
    for k in range(N):
        u = rd.random()
        S += 2.718281828 ** (-u * u)    # ou : import math ; math.exp(-u*u)
    return S / N

2. Sur \([0,1]\), \(t^2 \in [0,1]\) donc \(\mathrm{e}^{-1} \leqslant \mathrm{e}^{-t^2} \leqslant 1\) : l'intégrale est entre \(0{,}368\) et \(1\). Une sortie hors de cet intervalle signalerait un bug. (Avec \(N = 10^5\), la sortie est typiquement 0,745 – 0,749.)

Exercice 6 — Le problème des anniversaires, version simulation (type concours)

Approfondissement

Écrire une fonction freq_coincidence(n, N) qui estime, sur \(N\) simulations, la probabilité qu'au moins deux personnes parmi \(n\) partagent leur anniversaire (365 jours équiprobables). Que doit-elle renvoyer pour \(n = 23\) (cf. chapitre 10, exercice 8) ?

import random as rd

def freq_coincidence(n, N):
    c = 0
    for k in range(N):
        jours = [rd.randint(1, 365) for i in range(n)]
        # coïncidence ssi la liste contient un doublon :
        if len(set(jours)) < n:
            c += 1
    return c / N

Pour \(n = 23\), la valeur théorique est \(1 - q_{23} \approx 0{,}507\) : la fonction renvoie environ 0.507.

set(jours) supprime les doublons : comparer sa taille à \(n\) détecte une coïncidence. Sans set, on peut trier la liste et comparer les éléments consécutifs.

Exercice 9 — Maximum de deux dés

Application directe

Que estime cette fonction ? Donner la valeur théorique attendue.

import random as rd
def h(N):
    c = 0
    for k in range(N):
        a, b = rd.randint(1, 6), rd.randint(1, 6)
        if max(a, b) == 6:
            c = c + 1
    return c / N

Elle estime la probabilité que le plus grand de deux dés vaille 6. Théoriquement \(P(\max = 6) = \frac{2\times6 - 1}{36} = \frac{11}{36} \approx 0{,}306\) (chapitre 11, exercice 1).

Exercice 11 — Valider une binomiale

Entraînement

Écrire simule_binomiale(n, p), puis un programme estimant \(E(X)\) pour \(X \hookrightarrow \mathscr{B}(10 ;\ 0{,}3)\) sur 10 000 simulations. Valeur attendue ?

import random as rd

S = 0

Exercice 13 — Monte-Carlo pour \(\pi/4\)

Entraînement

Écrire une fonction Monte-Carlo estimant \(\displaystyle\int_0^1 \sqrt{1 - t^2}\,\mathrm{d}t\). Que vaut cette intégrale ?

import random as rd
def mc(N):
    S = 0
    for k in range(N):
        u = rd.random()
        S = S + (1 - u**2)**0.5
    return S / N

Par transfert, la moyenne estime \(E(\sqrt{1 - U^2}) = \int_0^1 \sqrt{1 - t^2}\,\mathrm{d}t\), qui est l'aire du quart de disque unité, soit \(\frac\pi4 \approx 0{,}785\).

Exercice 14 — Temps d'attente d'un six

import random as rd
def attente():

\(X\) suit une loi géométrique \(\mathscr{G}(\frac16)\) ; la moyenne d'un grand nombre d'appels tend vers \(E(X) = \frac1{1/6} = 6\).

Exercice 15 — Espérance d'un gain

Entraînement

Un jeu (chapitre 11, exercice 2) : tirage d'une carte parmi 32, un as rapporte 10 €, une figure 3 €, sinon 0 ; mise 2 €. Écrire simule_gain() et expliquer vers quoi tend la moyenne des gains.

import random as rd
def simule_gain():
    carte = rd.randint(1, 32)
    if carte <= 4:        # 4 as
        gain = 10
    elif carte <= 16:     # 12 figures
        gain = 3
    else:
        gain = 0
    return gain - 2       # on retranche la mise

La moyenne des gains simulés tend vers \(E(G) = 8\times\frac18 + 1\times\frac38 - 2\times\frac12 = 0{,}375\) € : le jeu est favorable.

Exercice 16 — Probabilité géométrique (type concours)

Approfondissement

Que estime cette fonction ? Donner la valeur exacte par un argument d'aire.

import random as rd
def freq(N):
    c = 0
    for k in range(N):
        if rd.random() + rd.random() <= 1:
            c = c + 1
    return c / N

On tire un point \((X, Y)\) uniforme dans le carré \([0,1]^2\) et on teste \(X + Y \leqslant 1\). La probabilité est l'aire du triangle sous la droite \(x + y = 1\), soit \(\frac12\). La fonction estime donc \(P(X + Y \leqslant 1) = 0{,}5\).

Exercice 17 — Marche aléatoire (type concours)

Approfondissement

Écrire marche(n) qui simule \(n\) pas \(\pm 1\) équiprobables et renvoie la position finale. Quelles sont l'espérance et la variance théoriques de cette position ?

import random as rd
def marche(n):
    S = 0
    for k in range(n):
        if rd.random() < 0.5:
            S = S + 1
        else:
            S = S - 1
    return S

La position \(S_n\) est une somme de \(n\) pas indépendants \(X_i \in \{-1, +1\}\) avec \(E(X_i) = 0\), \(V(X_i) = 1\). Donc \(E(S_n) = 0\) et \(V(S_n) = n\) (chapitre 15, exercice 18) : la moyenne des simulations approche 0, leur variance approche \(n\).

Exercice 18 — Problème du collectionneur (type concours)

Approfondissement

Écrire collectionneur(n) qui simule le nombre d'achats nécessaires pour obtenir les \(n\) vignettes différentes (chaque achat donne une vignette uniforme). Que vaut approximativement la moyenne pour \(n = 6\) ?

import random as rd
def collectionneur(n):
    obtenus = [False] * n
    nb = 0            # nombre de vignettes distinctes obtenues
    compteur = 0      # nombre d'achats
    while nb < n:
        c = rd.randint(0, n - 1)
        compteur = compteur + 1
        if not obtenus[c]:
            obtenus[c] = True
            nb = nb + 1
    return compteur

L'espérance théorique est \(n\,H_n = n\left(1 + \frac12 + \dots + \frac1n\right)\). Pour \(n = 6\) : \(6\times\frac{49}{20} = 14{,}7\) : la moyenne des simulations avoisine 14.7.

Exercice 19 — Ruine du joueur (type concours)

Approfondissement

Un joueur part avec \(k\) €, mise 1 € par partie (gain/perte équiprobable) et s'arrête à 0 € (ruine) ou \(N\) € (objectif). Écrire ruine(k, N) renvoyant True s'il atteint \(N\). Quelle est la probabilité théorique pour \(k = 3\), \(N = 10\) ?

import random as rd
def ruine(k, N):
    while 0 < k < N:
        if rd.random() < 0.5:
            k = k + 1
        else:
            k = k - 1
    return k == N

Pour un jeu équilibré, la probabilité d'atteindre \(N\) en partant de \(k\) est \(\frac kN\) (résultat classique). Pour \(k = 3\), \(N = 10\) : \(P = 0{,}3\) — la fréquence des True approche 0,3.

Exercice 20 — Fonction mystère (type concours)

Approfondissement

Que estime mystere(N) pour \(N\) grand ? Justifier par la symétrie.

import random as rd
def mystere(N):
    c = 0
    for k in range(N):
        x = rd.random()
        y = rd.random()
        if y <= x:
            c = c + 1
    return c / N

On tire deux uniformes indépendantes \(X, Y\) et on compte les cas \(Y \leqslant X\). Par symétrie des rôles de \(X\) et \(Y\) (et comme \(P(X = Y) = 0\)), \(P(Y \leqslant X) = P(X \leqslant Y) = \frac12\). La fonction estime donc \(0{,}5\).
