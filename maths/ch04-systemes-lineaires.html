Chapitre 4. Systèmes linéaires et méthode du pivot de Gauss

La méthode du pivot de Gauss est l'algorithme central de l'algèbre linéaire : elle résout n'importe quel système linéaire et servira au chapitre suivant pour inverser des matrices. L'objectif : une exécution rapide, sûre et bien rédigée.

Semestre 1 · ≈ 1 semaine de cours
Objectifs du chapitre (programme officiel)
  • Connaître le vocabulaire des systèmes linéaires (homogène, échelonné, pivot, équivalence).
  • Exécuter la méthode du pivot de Gauss proprement, en notant chaque opération élémentaire.
  • Reconnaître les trois situations : solution unique, aucune solution, infinité (paramétrer).
  • Discuter un système dépendant d'un paramètre par disjonction de cas.

1. Vocabulaire des systèmes linéaires

Définition 4.1 — Système linéaire

Un système linéaire de \(n\) équations à \(p\) inconnues \(x_1, \dots, x_p\) est un système de la forme :

\[ (S) : \begin{cases} a_{11} x_1 + a_{12} x_2 + \dots + a_{1p} x_p = b_1 \\ \vdots \\ a_{n1} x_1 + a_{n2} x_2 + \dots + a_{np} x_p = b_n \end{cases} \]

où les \(a_{ij}\) (coefficients) et les \(b_i\) (second membre) sont des réels donnés. Une solution est un \(p\)-uplet \((x_1, \dots, x_p)\) vérifiant simultanément toutes les équations. Le système est homogène si \(b_1 = \dots = b_n = 0\) (il admet toujours au moins la solution nulle). Deux systèmes sont équivalents s'ils ont le même ensemble de solutions.

Définition 4.2 — Système échelonné

Un système est échelonné si chaque équation commence par strictement plus d'inconnues « absentes » (coefficients nuls) que la précédente — visuellement, les équations forment un escalier. Le premier coefficient non nul de chaque ligne est appelé pivot. Un système échelonné se résout de bas en haut par remontée (substitutions successives).

2. Opérations élémentaires

Théorème 4.3 — Opérations élémentaires

Les trois opérations suivantes transforment un système en un système équivalent :

  • \(L_i \leftrightarrow L_j\) : échange de deux équations ;
  • \(L_i \leftarrow \lambda L_i\) avec \(\lambda \neq 0\) : multiplication d'une équation par un réel non nul ;
  • \(L_i \leftarrow L_i + \mu L_j\) (\(i \neq j\)) : ajout à une équation d'un multiple d'une autre.
Idée de la démonstration.

Chaque opération est réversible (l'échange par lui-même, la multiplication par \(\frac1\lambda\), l'ajout de \(-\mu L_j\)) : toute solution du système initial est solution du système transformé et réciproquement. ∎

Pièges
  • \(L_i \leftarrow 0 \times L_i\) est interdit (on perd une équation, donc de l'information).
  • Dans \(L_i \leftarrow L_i + \mu L_j\), la ligne modifiée doit apparaître avec le coefficient 1 : l'opération \(L_i \leftarrow 2L_j - 3L_i\) est licite (coefficient \(-3 \neq 0\) sur \(L_i\)) mais source d'erreurs — préférer la forme standard.
  • Ne faire qu'une opération par ligne et par étape, et toujours l'écrire en marge : c'est exigé par les correcteurs.

3. La méthode du pivot de Gauss

Méthode — Algorithme du pivot de Gauss
  1. Choisir un pivot non nul dans la première colonne (échanger des lignes si besoin ; préférer un pivot égal à 1).
  2. Éliminer la première inconnue de toutes les autres lignes par \(L_i \leftarrow L_i - \frac{a_{i1}}{a_{11}} L_1\).
  3. Recommencer sur le sous-système formé des lignes 2 à \(n\), avec la deuxième inconnue, etc.
  4. Le système obtenu est échelonné : le résoudre par remontée, de la dernière équation vers la première.

Exemple entièrement rédigé. Résolvons :

\[ (S) : \begin{cases} x + 2y - z = 3 \\ 2x - y + 3z = 1 \\ -x + y + 2z = 2 \end{cases} \]

Le pivot de la première colonne est le coefficient 1 de \(L_1\). Éliminons \(x\) dans \(L_2\) et \(L_3\) :

\[ \underset{\substack{L_2 \leftarrow L_2 - 2L_1 \\ L_3 \leftarrow L_3 + L_1}}{\Longleftrightarrow} \begin{cases} x + 2y - z = 3 \\ \phantom{x+{}} -5y + 5z = -5 \\ \phantom{x+{}} 3y + z = 5 \end{cases} \underset{L_2 \leftarrow -\frac15 L_2}{\Longleftrightarrow} \begin{cases} x + 2y - z = 3 \\ \phantom{x+{}} y - z = 1 \\ \phantom{x+{}} 3y + z = 5 \end{cases} \]

\[ \underset{L_3 \leftarrow L_3 - 3L_2}{\Longleftrightarrow} \begin{cases} x + 2y - z = 3 \\ \phantom{x+{}} y - z = 1 \\ \phantom{x+y+{}} 4z = 2 \end{cases} \]

Remontée : \(L_3\) donne \(z = \frac12\) ; \(L_2\) donne \(y = 1 + z = \frac32\) ; \(L_1\) donne \(x = 3 - 2y + z = 3 - 3 + \frac12 = \frac12\).

Conclusion : \(\mathscr{S} = \left\{\left(\frac12,\ \frac32,\ \frac12\right)\right\}\). Vérification rapide dans \(L_2\) : \(2 \cdot \frac12 - \frac32 + 3 \cdot \frac12 = 1 - \frac32 + \frac32 = 1\) ✓.

4. Les trois situations possibles

Théorème 4.4 — Structure de l'ensemble des solutions

Après échelonnement, trois cas seulement peuvent se produire :

  • Solution unique : le système échelonné a autant de pivots que d'inconnues (système de Cramer).
  • Aucune solution (système incompatible) : une ligne devient \(0 = c\) avec \(c \neq 0\).
  • Infinité de solutions : moins de pivots que d'inconnues et pas de ligne incompatible. Les inconnues sans pivot deviennent des paramètres et les solutions s'expriment en fonction d'eux.

Un système linéaire a donc 0, 1 ou une infinité de solutions — jamais exactement 2.

Exemple (infinité de solutions). \(\begin{cases} x + y - z = 1 \\ 2x - y + z = 0 \end{cases}\) : avec \(L_2 \leftarrow L_2 - 2L_1\), on obtient \(-3y + 3z = -2\), soit \(y = z + \frac23\). En reportant : \(x = 1 - y + z = \frac13\). L'ensemble des solutions est \(\mathscr{S} = \left\{\left(\frac13,\ t + \frac23,\ t\right) \mid t \in \mathbb{R}\right\}\) : une droite de solutions, paramétrée par \(t = z\).

5. Systèmes avec paramètre

Méthode — Discuter selon un paramètre \(m\)
  1. Échelonner en évitant si possible de choisir un pivot qui dépend de \(m\) (échanger lignes ou colonnes d'inconnues pour prendre un pivot constant).
  2. Quand un pivot potentiel vaut une expression en \(m\) : disjonction de cas — traiter à part les valeurs de \(m\) qui l'annulent.
  3. Conclure cas par cas : solution unique / aucune / infinité, en donnant les solutions.

Exemple rédigé. Discutons selon \(m \in \mathbb{R}\) le système \(\begin{cases} x + y = 1 \\ x + m y = m \end{cases}\).

\(L_2 \leftarrow L_2 - L_1\) donne \((m - 1)y = m - 1\).

  • Si \(m \neq 1\) : \(y = 1\) puis \(x = 0\). Solution unique \((0, 1)\).
  • Si \(m = 1\) : la seconde équation devient \(0 = 0\) ; il reste \(x + y = 1\) : infinité de solutions \(\{(1 - t,\ t) \mid t \in \mathbb{R}\}\).

Fiche de révision condensée

L'essentiel à relire juste avant un DS ou une colle
  • Opérations élémentaires (conservent l'ensemble des solutions) : \(L_i \leftrightarrow L_j\) ; \(L_i \leftarrow \lambda L_i\) (\(\lambda \neq 0\)) ; \(L_i \leftarrow L_i + \mu L_j\).
  • Gauss : choisir un pivot \(\neq 0\) → éliminer l'inconnue dans les autres lignes → échelonner → remonter.
  • 3 cas : autant de pivots que d'inconnues → solution unique ; ligne \(0 = c\) (\(c \neq 0\)) → aucune ; moins de pivots, pas d'incompatibilité → infinité (inconnues libres = paramètres).
  • Un système linéaire a 0, 1 ou une infinité de solutions, jamais exactement 2.
  • Homogène : \((0,\dots,0)\) toujours solution ; solutions non nulles ssi moins de pivots que d'inconnues.
  • Paramètre : disjonction de cas sur les valeurs annulant un pivot ; toujours noter les opérations en marge.

Exercices corrigés

Exercice 1 — Systèmes 2×2

Application directe

Résoudre : 1. \(\begin{cases} 2x + 3y = 7 \\ x - y = 1 \end{cases}\)   2. \(\begin{cases} x - 2y = 4 \\ -2x + 4y = -8 \end{cases}\)   3. \(\begin{cases} x + y = 2 \\ 2x + 2y = 5 \end{cases}\)

1. Échangeons pour avoir un pivot 1 : \(L_1 \leftrightarrow L_2\), puis \(L_2 \leftarrow L_2 - 2L_1\) : \(\begin{cases} x - y = 1 \\ 5y = 5 \end{cases}\), donc \(y = 1\), \(x = 2\). \(\mathscr{S} = \{(2, 1)\}\).

2. \(L_2 \leftarrow L_2 + 2L_1\) donne \(0 = 0\) : les deux équations sont proportionnelles. Infinité de solutions : \(x = 4 + 2t\), \(y = t\) : \(\mathscr{S} = \{(4 + 2t,\ t) \mid t \in \mathbb{R}\}\).

3. \(L_2 \leftarrow L_2 - 2L_1\) donne \(0 = 1\) : système incompatible, \(\mathscr{S} = \varnothing\).

Exercice 2 — Système 3×3 à solution unique

Application directe

Résoudre \(\begin{cases} x + y + z = 6 \\ 2x - y + z = 3 \\ x + 2y - z = 2 \end{cases}\)

\(L_2 \leftarrow L_2 - 2L_1\), \(L_3 \leftarrow L_3 - L_1\) :

\[ \begin{cases} x + y + z = 6 \\ -3y - z = -9 \\ y - 2z = -4 \end{cases} \]

\(L_2 \leftrightarrow L_3\) (pivot 1) puis \(L_3 \leftarrow L_3 + 3L_2\) :

\[ \begin{cases} x + y + z = 6 \\ y - 2z = -4 \\ -7z = -21 \end{cases} \]

Remontée : \(z = 3\), \(y = -4 + 2 \times 3 = 2\), \(x = 6 - 2 - 3 = 1\). \(\mathscr{S} = \{(1, 2, 3)\}\). Vérification dans \(L_2\) initiale : \(2 - 2 + 3 = 3\) ✓.

Exercice 3 — Système incompatible

Entraînement

Résoudre \(\begin{cases} x - y + 2z = 1 \\ 2x + y - z = 3 \\ 3x \phantom{+ y} + z = 5 \end{cases}\)

\(L_2 \leftarrow L_2 - 2L_1\), \(L_3 \leftarrow L_3 - 3L_1\) :

\[ \begin{cases} x - y + 2z = 1 \\ 3y - 5z = 1 \\ 3y - 5z = 2 \end{cases} \]

\(L_3 \leftarrow L_3 - L_2\) donne \(0 = 1\) : contradiction. \(\mathscr{S} = \varnothing\).

Interprétation : la troisième équation « ressemble » à la somme des deux premières (\(L_1 + L_2\) donne \(3x + z = 4\)), mais avec un second membre différent (5 au lieu de 4) : les contraintes sont incompatibles.

Exercice 4 — Infinité de solutions

Entraînement

Résoudre \(\begin{cases} x + 2y - z = 4 \\ 2x - y + 3z = 3 \\ 3x + y + 2z = 7 \end{cases}\)

\(L_2 \leftarrow L_2 - 2L_1\), \(L_3 \leftarrow L_3 - 3L_1\) :

\[ \begin{cases} x + 2y - z = 4 \\ -5y + 5z = -5 \\ -5y + 5z = -5 \end{cases} \]

\(L_3 \leftarrow L_3 - L_2\) donne \(0 = 0\) : il reste 2 pivots pour 3 inconnues. \(L_2\) (divisée par \(-5\)) donne \(y = z + 1\). En reportant dans \(L_1\) : \(x = 4 - 2(z+1) + z = 2 - z\).

\(\mathscr{S} = \{(2 - t,\ 1 + t,\ t) \mid t \in \mathbb{R}\}\).

Exercice 5 — Système 4 équations, 3 inconnues

Entraînement

Résoudre \(\begin{cases} x + y + z = 3 \\ x - y + z = 1 \\ 2x + y - z = 2 \\ x + 2y + 2z = 5 \end{cases}\)

\(L_2 \leftarrow L_2 - L_1\), \(L_3 \leftarrow L_3 - 2L_1\), \(L_4 \leftarrow L_4 - L_1\) :

\[ \begin{cases} x + y + z = 3 \\ -2y = -2 \\ -y - 3z = -4 \\ y + z = 2 \end{cases} \]

\(L_2\) donne \(y = 1\). Alors \(L_3\) : \(-1 - 3z = -4\), soit \(z = 1\) ; et \(L_4\) : \(1 + 1 = 2\) ✓ (compatible). Enfin \(x = 3 - 1 - 1 = 1\).

\(\mathscr{S} = \{(1, 1, 1)\}\). Avec plus d'équations que d'inconnues, il faut vérifier que les équations « en trop » sont compatibles — ici oui.

Exercice 6 — Problème concret

Entraînement

Une entreprise fabrique trois produits A, B, C. Produire une unité de A coûte 2 h de main-d'œuvre, 1 kg de matière et 3 kWh d'énergie ; une unité de B : 1 h, 2 kg, 1 kWh ; une unité de C : 3 h, 1 kg, 2 kWh. On dispose exactement de 16 h, 13 kg et 17 kWh. Combien d'unités de chaque produit fabriquer pour tout utiliser ?

Notons \(a, b, c\) les quantités de A, B, C. Les contraintes (heures, matière, énergie) donnent :

\[ \begin{cases} 2a + b + 3c = 16 \\ a + 2b + c = 13 \\ 3a + b + 2c = 17 \end{cases} \]

Mettons \(L_2\) en tête (pivot 1) : \(L_1 \leftrightarrow L_2\), puis \(L_2 \leftarrow L_2 - 2L_1\) et \(L_3 \leftarrow L_3 - 3L_1\) :

\[ \begin{cases} a + 2b + c = 13 \\ -3b + c = -10 \\ -5b - c = -22 \end{cases} \]

\(L_3 \leftarrow L_3 + L_2\) élimine \(c\) : \(-8b = -32\), donc \(b = 4\).

Remontée : \(L_2\) donne \(c = -10 + 3b = 2\) ; \(L_1\) donne \(a = 13 - 2b - c = 13 - 8 - 2 = 3\).

\(\mathscr{S} = \{(3,\ 4,\ 2)\}\) : l'entreprise doit produire 3 unités de A, 4 de B et 2 de C. Vérification (énergie) : \(3 \times 3 + 1 \times 4 + 2 \times 2 = 17\) ✓.

Exercice 7 — Système avec paramètre

Approfondissement

Discuter et résoudre selon \(m \in \mathbb{R}\) : \(\begin{cases} x + y + mz = 1 \\ x + my + z = 1 \\ mx + y + z = 1 \end{cases}\)

\(L_2 \leftarrow L_2 - L_1\), \(L_3 \leftarrow L_3 - mL_1\) :

\[ \begin{cases} x + y + mz = 1 \\ (m-1)y + (1-m)z = 0 \\ (1-m)y + (1-m^2)z = 1-m \end{cases} \]

Cas \(m = 1\) : les lignes 2 et 3 deviennent \(0 = 0\) ; il reste \(x + y + z = 1\) : infinité de solutions \(\{(1 - s - t,\ s,\ t) \mid s, t \in \mathbb{R}\}\).

Cas \(m \neq 1\) : divisons \(L_2\) par \(m - 1\) : \(y - z = 0\), soit \(y = z\). Divisons \(L_3\) par \(1 - m\) : \(y + (1+m)z = 1\). Avec \(y = z\) : \((2 + m)z = 1\).

  • Si \(m = -2\) : \(0 = 1\), incompatible : \(\mathscr{S} = \varnothing\).
  • Si \(m \neq -2\) (et \(m \neq 1\)) : \(z = y = \dfrac{1}{m+2}\), puis \(x = 1 - y - mz = 1 - \dfrac{1+m}{m+2} = \dfrac{1}{m+2}\).

Conclusion : solution unique \(\left(\frac{1}{m+2}, \frac{1}{m+2}, \frac{1}{m+2}\right)\) si \(m \notin \{1, -2\}\) ; infinité si \(m = 1\) ; aucune si \(m = -2\).

Exercice 8 — Ajustement polynomial (type concours)

Approfondissement

Déterminer le polynôme \(P(x) = ax^2 + bx + c\) tel que \(P(1) = 2\), \(P(2) = 5\) et \(P(-1) = 2\).

Les trois conditions donnent le système :

\[ \begin{cases} a + b + c = 2 \\ 4a + 2b + c = 5 \\ a - b + c = 2 \end{cases} \]

\(L_2 \leftarrow L_2 - 4L_1\), \(L_3 \leftarrow L_3 - L_1\) :

\[ \begin{cases} a + b + c = 2 \\ -2b - 3c = -3 \\ -2b = 0 \end{cases} \]

\(L_3\) donne \(b = 0\) ; \(L_2\) donne \(c = 1\) ; \(L_1\) donne \(a = 1\).

Donc \(P(x) = x^2 + 1\). Vérification : \(P(1) = 2\) ✓, \(P(2) = 5\) ✓, \(P(-1) = 2\) ✓.

Exercice 9 — Système homogène avec paramètre (type concours)

Approfondissement

Pour quelles valeurs de \(m\) le système \(\begin{cases} x + 2y + z = 0 \\ 2x + y - z = 0 \\ x - y + mz = 0 \end{cases}\) admet-il des solutions non nulles ? Les déterminer.

Système homogène : \((0,0,0)\) est toujours solution ; il y a des solutions non nulles ssi le système échelonné a moins de 3 pivots.

\(L_2 \leftarrow L_2 - 2L_1\), \(L_3 \leftarrow L_3 - L_1\) :

\[ \begin{cases} x + 2y + z = 0 \\ -3y - 3z = 0 \\ -3y + (m-1)z = 0 \end{cases} \]

\(L_3 \leftarrow L_3 - L_2\) : \((m - 1 + 3)z = 0\), soit \((m+2)z = 0\).

  • Si \(m \neq -2\) : \(z = 0\), puis \(y = 0\), puis \(x = 0\) : seule la solution nulle.
  • Si \(m = -2\) : \(z\) est libre ; \(y = -z\) (de \(L_2\)) et \(x = -2y - z = z\). Solutions : \(\mathscr{S} = \{(t,\ -t,\ t) \mid t \in \mathbb{R}\}\), non nulles pour \(t \neq 0\).

Réponse : \(m = -2\), avec la droite de solutions \((t, -t, t)\).

Exercice 10 — Système 2×2 par substitution

Application directe

Résoudre \(\begin{cases} 3x + 2y = 8 \\ x - y = 1 \end{cases}\)

\(L_2\) donne \(x = y + 1\). En reportant dans \(L_1\) : \(3(y+1) + 2y = 8 \iff 5y = 5 \iff y = 1\), d'où \(x = 2\). \(\mathscr{S} = \{(2, 1)\}\).

Exercice 11 — Système 3×3 à solution unique

Application directe

Résoudre \(\begin{cases} x + y + z = 6 \\ x - y + 2z = 5 \\ 2x + y - z = 1 \end{cases}\)

\(L_2 \leftarrow L_2 - L_1\), \(L_3 \leftarrow L_3 - 2L_1\) :

\[ \begin{cases} x + y + z = 6 \\ -2y + z = -1 \\ -y - 3z = -11 \end{cases} \]

De \(L_2\) : \(z = 2y - 1\). En reportant dans \(L_3\) : \(-y - 3(2y-1) = -11 \iff -7y = -14 \iff y = 2\), d'où \(z = 3\) et \(x = 6 - 2 - 3 = 1\). \(\mathscr{S} = \{(1, 2, 3)\}\). Vérification (\(L_2\)) : \(1 - 2 + 6 = 5\) ✓.

Exercice 12 — Remontée d'un système échelonné

Application directe

Résoudre par remontée \(\begin{cases} x + 2y - z = 3 \\ y + 2z = 5 \\ 3z = 6 \end{cases}\)

\(L_3\) donne \(z = 2\) ; \(L_2\) donne \(y = 5 - 2 \times 2 = 1\) ; \(L_1\) donne \(x = 3 - 2 \times 1 + 2 = 3\). \(\mathscr{S} = \{(3, 1, 2)\}\).

Exercice 13 — Infinité de solutions (3×3)

Entraînement

Résoudre \(\begin{cases} x + y + z = 2 \\ 2x + 3y + z = 3 \\ x + 2y \phantom{{}+ z} = 1 \end{cases}\)

\(L_2 \leftarrow L_2 - 2L_1\), \(L_3 \leftarrow L_3 - L_1\) :

\[ \begin{cases} x + y + z = 2 \\ y - z = -1 \\ y - z = -1 \end{cases} \]

\(L_3 \leftarrow L_3 - L_2\) donne \(0 = 0\) : deux pivots pour trois inconnues. De \(L_2\) : \(y = z - 1\) ; de \(L_1\) : \(x = 2 - y - z = 2 - (z-1) - z = 3 - 2z\).

\(\mathscr{S} = \{(3 - 2t,\ t - 1,\ t) \mid t \in \mathbb{R}\}\).

Exercice 14 — Système homogène

Entraînement

Résoudre \(\begin{cases} x + y - z = 0 \\ 2x - y + z = 0 \\ x - 2y + 2z = 0 \end{cases}\)

\(L_2 \leftarrow L_2 - 2L_1\), \(L_3 \leftarrow L_3 - L_1\) :

\[ \begin{cases} x + y - z = 0 \\ -3y + 3z = 0 \\ -3y + 3z = 0 \end{cases} \]

\(L_3 \leftarrow L_3 - L_2\) donne \(0 = 0\) : \(L_2\) fournit \(y = z\), et \(L_1\) donne \(x = z - y = 0\). \(\mathscr{S} = \{(0,\ t,\ t) \mid t \in \mathbb{R}\}\) : le système admet des solutions non nulles.

Exercice 15 — Problème de prix

Entraînement

Sur un marché, trois paniers de fruits sont vendus : 2 kg de pommes + 1 kg de poires + 1 kg de cerises coûtent 11 € ; 1 + 2 + 1 coûtent 12 € ; 1 + 1 + 2 coûtent 13 €. Déterminer le prix au kilo de chaque fruit.

Notons \(p, q, r\) les prix au kilo (pommes, poires, cerises) :

\[ \begin{cases} 2p + q + r = 11 \\ p + 2q + r = 12 \\ p + q + 2r = 13 \end{cases} \]

En additionnant les trois équations : \(4(p + q + r) = 36\), donc \(p + q + r = 9\). En retranchant cette relation de chaque équation : \(p = 11 - 9 = 2\), \(q = 12 - 9 = 3\), \(r = 13 - 9 = 4\).

Les pommes coûtent 2 €/kg, les poires 3 €/kg, les cerises 4 €/kg. Vérification : \(2 \times 2 + 3 + 4 = 11\) ✓.

Exercice 16 — Trois nombres

Entraînement

La somme de trois nombres vaut 12. Le premier plus le double du deuxième vaut 11. Le troisième dépasse le premier de 2. Déterminer ces trois nombres.

\(\begin{cases} x + y + z = 12 \\ x + 2y = 11 \\ z - x = 2 \end{cases}\) De \(L_3\) : \(z = x + 2\). En reportant dans \(L_1\) : \(2x + y = 10\). Avec \(L_2\) (\(x + 2y = 11\)) : \(y = 10 - 2x\), puis \(x + 2(10 - 2x) = 11 \iff -3x = -9 \iff x = 3\), d'où \(y = 4\), \(z = 5\).

Les nombres sont \(3, 4, 5\). Vérification : \(3 + 4 + 5 = 12\) ✓, \(3 + 8 = 11\) ✓.

Exercice 17 — Système avec paramètre

Approfondissement

Discuter et résoudre selon \(m \in \mathbb{R}\) : \(\begin{cases} x + y + z = 1 \\ 2x + y + 3z = 3 \\ x - y + mz = 0 \end{cases}\)

\(L_2 \leftarrow L_2 - 2L_1\), \(L_3 \leftarrow L_3 - L_1\) :

\[ \begin{cases} x + y + z = 1 \\ -y + z = 1 \\ -2y + (m-1)z = -1 \end{cases} \]

De \(L_2\) : \(y = z - 1\). En reportant dans \(L_3\) : \(-2(z-1) + (m-1)z = -1\), soit \((m - 3)z = -3\).

  • Si \(m \neq 3\) : \(z = \dfrac{3}{3 - m}\), puis \(y = z - 1\) et \(x = 1 - y - z = 2 - 2z\) : solution unique.
  • Si \(m = 3\) : la ligne devient \(0 = -3\), impossible : \(\mathscr{S} = \varnothing\).

Vérification pour \(m = 0\) : \(z = 1\), \(y = 0\), \(x = 0\) ; on a bien \(0 + 0 + 1 = 1\), \(0 + 0 + 3 = 3\), \(0 - 0 + 0 = 0\). ✓

Exercice 18 — Interpolation polynomiale

Approfondissement

Déterminer le polynôme \(P(x) = ax^3 + bx^2 + cx + d\) de degré au plus 3 tel que \(P(0) = 1\), \(P(1) = 0\), \(P(-1) = 6\) et \(P(2) = 3\).

Les conditions donnent : \(d = 1\) (par \(P(0)\)), puis :

\[ \begin{cases} a + b + c = -1 \\ -a + b - c = 5 \\ 4a + 2b + c = 1 \end{cases} \]

La somme des deux premières donne \(2b = 4\), soit \(b = 2\), d'où \(a + c = -3\). La troisième devient \(4a + c = -3\). En soustrayant : \(3a = 0\), donc \(a = 0\) et \(c = -3\).

Ainsi \(P(x) = 2x^2 - 3x + 1\) (le coefficient de \(x^3\) est nul : le polynôme cherché est en fait de degré 2). Vérification : \(P(2) = 8 - 6 + 1 = 3\) ✓, \(P(-1) = 2 + 3 + 1 = 6\) ✓.

Exercice 19 — Système homogène symétrique (type concours)

Approfondissement

Pour quelles valeurs de \(a \in \mathbb{R}\) le système \(\begin{cases} x + ay + z = 0 \\ ax + y + z = 0 \\ x + y + az = 0 \end{cases}\) admet-il des solutions non nulles ? Les décrire.

Par différences : \(L_1 - L_2 = (1 - a)(x - y) = 0\) et \(L_1 - L_3 = (a - 1)(y - z) = 0\).

Cas \(a = 1\) : les trois équations se réduisent à \(x + y + z = 0\) : une infinité de solutions (un plan), \(\mathscr{S} = \{(x, y, z) \mid x + y + z = 0\}\).

Cas \(a \neq 1\) : les différences imposent \(x = y = z\). En reportant dans \(L_1\) : \((2 + a)x = 0\).

  • si \(a \neq -2\) : \(x = 0\), donc seule la solution nulle ;
  • si \(a = -2\) : \(x = y = z\) libre, \(\mathscr{S} = \{(t, t, t) \mid t \in \mathbb{R}\}\).

Réponse : solutions non nulles si et seulement si \(a = 1\) ou \(a = -2\).

Exercice 20 — Système 3 équations, 4 inconnues (type concours)

Approfondissement

Résoudre dans \(\mathbb{R}^4\) : \(\begin{cases} x + y + z + t = 0 \\ x + 2y + 3z + 4t = 0 \\ x + 3y + 6z + 10t = 0 \end{cases}\)

\(L_2 \leftarrow L_2 - L_1\), \(L_3 \leftarrow L_3 - L_1\) :

\[ \begin{cases} x + y + z + t = 0 \\ y + 2z + 3t = 0 \\ 2y + 5z + 9t = 0 \end{cases} \]

\(L_3 \leftarrow L_3 - 2L_2\) : \(z + 3t = 0\), soit \(z = -3t\). Puis \(L_2\) : \(y = -2z - 3t = 6t - 3t = 3t\) ; et \(L_1\) : \(x = -y - z - t = -3t + 3t - t = -t\).

\(\mathscr{S} = \{(-t,\ 3t,\ -3t,\ t) \mid t \in \mathbb{R}\}\) : une droite de solutions (3 pivots, 4 inconnues, donc 1 paramètre). Vérification (\(L_3\)) : \(-t + 9t - 18t + 10t = 0\) ✓.
