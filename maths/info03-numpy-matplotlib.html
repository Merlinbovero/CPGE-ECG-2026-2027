Informatique I3. Les bibliothèques numpy, matplotlib et random

Trois bibliothèques au programme : numpy pour le calcul numérique et matriciel, matplotlib.pyplot pour les graphiques, random pour l'aléatoire (développé en fiche I4). Les imports standards à connaître par cœur : import numpy as np, import matplotlib.pyplot as plt, import random as rd.

1. Tableaux numpy

import numpy as np

A = np.array([1, 2, 3, 4])        # tableau 1D à partir d'une liste
Z = np.zeros(5)                   # [0. 0. 0. 0. 0.]
U = np.ones(3)                    # [1. 1. 1.]
E = np.arange(0, 10, 2)           # [0 2 4 6 8]  (comme range)
X = np.linspace(0, 1, 5)          # [0.   0.25 0.5  0.75 1.  ]  (5 points régulièrement espacés)

np.linspace(a, b, n) donne \(n\) points de \(a\) à \(b\) inclus — c'est l'outil standard pour tracer une fonction.

2. Opérations vectorisées

Les opérations s'appliquent terme à terme, sans boucle :

A = np.array([1, 2, 3, 4])
print(A + 1)        # [2 3 4 5]
print(2 * A)        # [2 4 6 8]
print(A ** 2)       # [ 1  4  9 16]
print(np.sqrt(A))   # [1.    1.414 1.732 2.   ]
print(np.exp(A), np.log(A))   # exponentielle et ln, terme à terme
print(A.sum(), A.mean(), A.max())   # 10  2.5  4
print(A[A > 2])     # [3 4]  (sélection par condition)
print((A % 2 == 0).sum())     # 2  (nombre de termes pairs)
Piège

Avec des listes Python, 2 * [1, 2] donne [1, 2, 1, 2] (répétition) et [1, 2] + [3] donne [1, 2, 3] (concaténation). Les mêmes opérateurs sur des tableaux numpy font du calcul terme à terme. Identifier le type avant de prédire la sortie !

3. Matrices avec numpy

M = np.array([[1, 2], [3, 4]])    # matrice 2x2
I = np.eye(2)                      # matrice identité
print(M.shape)                     # (2, 2)
print(M[0, 1])                     # 2   (ligne 0, colonne 1)
print(M + M)                       # somme terme à terme
print(M * M)                       # ATTENTION : produit terme à terme !
print(np.dot(M, M))                # produit MATRICIEL : [[ 7 10] [15 22]]
print(M @ M)                       # idem, notation moderne
P = np.linalg.matrix_power(M, 3)   # M au cube (produit matriciel)
X = np.linalg.solve(M, np.array([1, 2]))   # résout MX = B
Le piège matriciel du concours

M * N est le produit terme à terme ; le produit matriciel est np.dot(M, N) ou M @ N. De même M ** 2 élève chaque coefficient au carré — pour \(M^2\) au sens matriciel, utiliser np.linalg.matrix_power(M, 2) ou M @ M.

4. Graphiques avec matplotlib

import numpy as np
import matplotlib.pyplot as plt

# Courbe d'une fonction
x = np.linspace(-2, 2, 200)
plt.plot(x, np.exp(x), label="exp")
plt.plot(x, 1 + x, "--", label="tangente en 0")
plt.legend()
plt.xlabel("x")
plt.title("exp est au-dessus de sa tangente (convexité)")
plt.show()

# Termes d'une suite (points isolés)
n = np.arange(20)
plt.plot(n, 3 * 0.8**n, "o")      # "o" : marqueurs ronds
plt.show()

# Diagramme en bâtons d'une loi binomiale, histogramme de données
plt.bar(valeurs, probas)
plt.hist(donnees, bins=20)

À l'écrit, on demande surtout d'interpréter un graphique produit par un code donné, ou de compléter l'appel plt.plot.

5. Le module random

import random as rd

rd.random()          # un float uniforme dans [0, 1[
rd.randint(1, 6)     # un entier uniforme entre 1 et 6 INCLUS (lancer de dé)
rd.choice([2, 3, 5]) # un élément au hasard dans la liste

Simuler une épreuve de Bernoulli de paramètre \(p\) : rd.random() < p renvoie True avec probabilité \(p\). La fiche I4 développe les simulations complètes.

Remarque : np.random.rand(n) (numpy) produit directement un tableau de \(n\) uniformes — utile pour vectoriser les simulations.

Exercice 1 — Prédire la sortie (numpy)

Application directe
import numpy as np
A = np.arange(1, 6)
print(A)
print(A * A)
print(A.sum())
print((A ** 2).sum())
L = [1, 2, 3]

[1 2 3 4 5] ; [ 1 4 9 16 25] (produit terme à terme) ; 15 ; 55 (somme des carrés) ; [1, 2, 3, 1, 2, 3] — car L est une liste, pas un tableau : répétition.

Exercice 2 — Puissances de matrices

Application directe

Écrire un programme numpy qui calcule \(A^{10}\) pour \(A = \begin{pmatrix} 1 & 1 \\ 0 & 1 \end{pmatrix}\), et prédire le résultat (cf. chapitre 5, exercice 6).

import numpy as np
A = np.array([[1, 1], [0, 1]])
P = np.linalg.matrix_power(A, 10)
print(P)

D'après la formule \(A^k = \begin{pmatrix} 1 & k \\ 0 & 1 \end{pmatrix}\), le programme affiche [[ 1 10] [ 0 1]].

Exercice 3 — Tracer une étude de fonction

Entraînement

Écrire le code qui trace \(f(x) = \frac{\ln x}{x}\) sur \([0{,}1 ; 8]\) ainsi que la droite horizontale \(y = 1/\mathrm{e}\), pour illustrer le maximum obtenu au chapitre 8.

import numpy as np
import matplotlib.pyplot as plt

x = np.linspace(0.1, 8, 300)
plt.plot(x, np.log(x) / x, label="f(x) = ln(x)/x")
plt.axhline(1/np.e, linestyle="--", color="gray", label="y = 1/e")
plt.axvline(np.e, linestyle=":", color="gray")
plt.legend()
plt.show()

La courbe monte jusqu'à \(x = \mathrm{e} \approx 2{,}72\) où elle touche la droite \(y = 1/\mathrm{e} \approx 0{,}368\), puis redescend vers 0 : c'est le tableau de variations du chapitre 8 en image.

Exercice 4 — Suite récurrente et graphique

Entraînement

Écrire un programme qui calcule les 30 premiers termes de la suite \(u_0 = 0\), \(u_{n+1} = \sqrt{u_n + 2}\) (chapitre 6, exercice 7) et les représente. Quelle allure attend-on ?

import numpy as np
import matplotlib.pyplot as plt

u = [0]
for n in range(29):
    u.append(np.sqrt(u[-1] + 2))

plt.plot(range(30), u, "o-")
plt.axhline(2, linestyle="--", color="gray")
plt.xlabel("n"); plt.ylabel("u_n")
plt.show()

Allure attendue : une suite croissante qui converge très vite vers la droite \(y = 2\) (limite démontrée au chapitre 6) — dès \(n \approx 5\), les points sont visuellement confondus avec 2.

Exercice 5 — Marche vers l'équilibre (type concours)

Approfondissement

On reprend le serveur du chapitre 10 (exercice 7) : \(p_{n+1} = 0{,}3p_n + 0{,}6\), \(p_0 = 1\). Compléter le programme pour qu'il affiche le plus petit \(n\) tel que \(|p_n - \frac67| \leqslant 10^{-6}\), et estimer ce \(n\) par le calcul.

p = 1
n = 0
while ......:
    p = ......
    n = ......
print(n)
p = 1
n = 0
while abs(p - 6/7) > 1e-6:
    p = 0.3 * p + 0.6
    n = n + 1
print(n)

Estimation : d'après le chapitre 10, \(p_n - \frac67 = \frac17(0{,}3)^n\). On veut \(\frac17 (0{,}3)^n \leqslant 10^{-6}\), soit \(n \geqslant \frac{\ln(7 \times 10^{-6})}{\ln 0{,}3} = \frac{-11{,}87}{-1{,}204} \approx 9{,}86\) : le programme affiche 10.

Exercice 6 — Chemins dans un graphe avec numpy (type concours)

Approfondissement

Écrire un programme qui, pour le graphe du chapitre 16 (matrice \(A\) donnée ci-dessous), calcule le nombre de chemins de longueur 4 entre les sommets 1 et 4, et vérifier le résultat à la main à partir de \(A^2\).

import numpy as np
A = np.array([[0,1,1,0],
              [1,0,1,1],
              [1,1,0,0],
              [0,1,0,0]])
P4 = np.linalg.matrix_power(A, 4)
print(P4[0, 3])    # sommets 1 et 4 : indices 0 et 3 !

Vérification : \(A^4 = (A^2)^2\), avec \(A^2\) calculée au chapitre 16 (exercice 3). Le coefficient \((1,4)\) de \(A^4\) est le produit scalaire de la ligne 1 de \(A^2\), \((2, 1, 1, 1)\), par la colonne 4 de \(A^2\), \((1, 0, 1, 1)\) : \(2 \times 1 + 1 \times 0 + 1 \times 1 + 1 \times 1 = 4\). Le programme affiche 4.

Noter le décalage sommets/indices : le sommet 1 est l'indice 0 — piège récurrent.
