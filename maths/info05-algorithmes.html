Informatique I5. Suites, algorithmes de seuil et dichotomie

Trois algorithmes emblématiques du programme, en lien direct avec l'analyse : calculer les termes d'une suite récurrente, déterminer un rang de seuil (boucle while), et localiser un zéro de fonction par dichotomie.

TP tout au long de l'année
Objectifs de la fiche (programme officiel)
  • Calculer les termes d'une suite récurrente d'ordre 1 (une variable) ou 2 (deux variables, affectation simultanée).
  • Écrire un algorithme de seuil (boucle while) donnant le premier rang vérifiant une condition, et en déduire un résultat par le calcul.
  • Mettre en œuvre la dichotomie pour approcher un zéro de fonction (hypothèses du TVI) et connaître le nombre d'itérations \(\log_2\frac{b-a}{\varepsilon}\).
  • Estimer la complexité d'un algorithme (linéaire, quadratique, logarithmique) et adopter de bonnes pratiques (tests, invariants).

1. Calculer les termes d'une suite

Suite récurrente d'ordre 1 \(u_{n+1} = f(u_n)\) : une variable suffit, mise à jour \(n\) fois.

def u(n):
    x = 2                    # u_0
    for k in range(n):
        x = 0.5 * x + 3      # x reçoit u_{k+1}
    return x

Suite d'ordre 2 \(u_{n+2} = a u_{n+1} + b u_n\) : deux variables mises à jour simultanément.

def v(n):
    x, y = 1, 8              # v_0, v_1
    for k in range(n):
        x, y = y, 4*y - 4*x  # (v_k, v_{k+1}) devient (v_{k+1}, v_{k+2})
    return x                 # après n itérations, x contient v_n
Piège

Écrire x = y puis y = 4*y - 4*x sur deux lignes est faux : la seconde ligne utiliserait le nouveau x. L'affectation simultanée x, y = y, 4*y - 4*x (ou une variable temporaire) est indispensable.

2. Algorithmes de seuil

Méthode — Rang de seuil

Question type : « la suite \((u_n)\) converge vers \(\ell\) ; écrire un programme donnant le plus petit \(n\) tel que \(|u_n - \ell| \leqslant \varepsilon\) » (ou : tel que \(u_n\) dépasse un seuil \(A\)). Structure invariable :

x = u0
n = 0
while abs(x - l) > eps:      # ou : while x <= A
    x = f(x)                  # terme suivant
    n = n + 1
print(n)

Points de vigilance : la condition du while est la négation de l'objectif ; n et x doivent rester synchronisés (après la boucle, x vaut \(u_n\)) ; la boucle doit terminer (la convergence de la suite le garantit).

3. La dichotomie

Objectif : approcher la solution \(\alpha\) de \(f(x) = 0\) sur \([a, b]\), sachant \(f\) continue avec \(f(a)\) et \(f(b)\) de signes opposés (TVI, chapitre 7). Idée : couper l'intervalle en deux et garder la moitié où le signe change ; la longueur est divisée par 2 à chaque étape.

def dichotomie(f, a, b, eps):
    """Renvoie une valeur approchée à eps près d'une solution de f(x) = 0,
    en supposant f(a) et f(b) de signes opposés."""
    while b - a > eps:
        m = (a + b) / 2
        if f(a) * f(m) <= 0:    # le zéro est dans [a, m]
            b = m
        else:                    # sinon il est dans [m, b]
            a = m
    return (a + b) / 2

# Exemple : la solution de x**3 + x - 1 = 0 (chapitre 7, exercice 5)
def g(x):
    return x**3 + x - 1
print(dichotomie(g, 0, 1, 1e-6))   # affiche : 0.6823277...
Précision et nombre d'itérations

Après \(k\) itérations, l'intervalle a pour longueur \(\dfrac{b-a}{2^k}\). Pour une précision \(\varepsilon\), il faut \(k \geqslant \log_2\frac{b-a}{\varepsilon}\) itérations : par exemple 20 itérations suffisent pour \(\varepsilon = 10^{-6}\) sur \([0,1]\) — la dichotomie est très efficace.

4. Bonnes pratiques et complexité

  • Tester sur des petits cas dont on connaît la réponse (\(n = 0\), \(n = 1\)).
  • Compter les opérations : une boucle de \(n\) itérations a un coût proportionnel à \(n\) (linéaire) ; deux boucles imbriquées : \(n^2\) (quadratique) ; la dichotomie : \(\log_2 n\) (logarithmique).
  • Pour une suite, ne stocker tous les termes (liste) que si on en a besoin (tracé, moyenne) ; sinon, une variable suffit.
  • Nommer clairement, commenter les initialisations, et vérifier les invariants (« après la boucle, x contient \(u_n\) »).
Fiche de révision condensée
  • Suite ordre 1 : x = u0 ; for k in range(n): x = f(x) ; return x.
  • Suite ordre 2 : x, y = u0, u1 ; for k in range(n): x, y = y, a*y + b*x ; return x (affectation simultanée).
  • Seuil : n = 0 ; while (négation de l'objectif): x = f(x) ; n += 1 ; print(n).
  • Dichotomie : tant que b - a > eps, \(m = \frac{a+b}2\) ; si f(a)*f(m) <= 0 alors b = m sinon a = m.
  • Itérations dichotomie : \(k \geqslant \log_2\frac{b-a}{\varepsilon}\) (précision divisée par 2 à chaque tour).
  • Complexité : une boucle → linéaire \(\mathcal O(n)\) ; deux imbriquées → \(\mathcal O(n^2)\) ; dichotomie → \(\mathcal O(\log n)\).
  • Invariant : après la boucle, la variable contient bien le terme voulu — à vérifier sur \(n = 0, 1\).

Exercices corrigés

Exercice 1 — Termes d'une suite d'ordre 2

Application directe

La suite du chapitre 6 vérifie \(u_0 = 3\), \(u_1 = 4\), \(u_{n+2} = \frac52 u_{n+1} - u_n\). Écrire u(n) et donner la valeur renvoyée par u(2).

def u(n):
    x, y = 3, 4
    for k in range(n):
        x, y = y, 2.5*y - x
    return x

u(2) : après une itération, \((x, y) = (4, 7)\) ; après deux, \((7, 13{,}5)\) ; renvoie 7 — conforme à \(u_2 = \frac52 \times 4 - 3 = 7\) ✓.

Exercice 2 — Seuil sur une suite géométrique

Application directe

Écrire un programme donnant le plus petit \(n\) tel que \(0{,}8^n \leqslant 0{,}01\), puis retrouver ce résultat par le calcul.

x = 1        # 0.8**0
n = 0
while x > 0.01:
    x = 0.8 * x
    n += 1
print(n)

Calcul : \(0{,}8^n \leqslant 10^{-2} \iff n \ln 0{,}8 \leqslant -2\ln 10 \iff n \geqslant \frac{2\ln 10}{\ln(1/0{,}8)} = \frac{4{,}605}{0{,}223} \approx 20{,}6\). Le programme affiche 21.

Exercice 3 — Compléter une dichotomie (format concours)

Entraînement

Compléter le programme pour qu'il affiche une valeur approchée à \(10^{-4}\) près de la solution de \(\ln x + x = 0\) (chapitre 7, exercice 7), située dans \([\frac12, 1]\) :

import numpy as np
a, b = 0.5, 1
while ......:
    m = (a + b) / 2
    if (np.log(a) + a) * (np.log(m) + m) <= 0:
        ......
    else:
        ......
print((a + b) / 2)
import numpy as np
a, b = 0.5, 1
while b - a > 1e-4:
    m = (a + b) / 2
    if (np.log(a) + a) * (np.log(m) + m) <= 0:
        b = m        # changement de signe sur [a, m] : on garde la gauche
    else:
        a = m
print((a + b) / 2)   # affiche 0.5671... (la constante Oméga)

Il faut \(\lceil\log_2 \frac{0{,}5}{10^{-4}}\rceil = 13\) itérations.

Exercice 4 — Seuil et série (type concours)

Entraînement

On note \(S_N = \sum_{n=1}^{N} \frac{1}{n^2}\), qui converge vers \(\frac{\pi^2}{6} \approx 1{,}6449\). Écrire un programme qui affiche le plus petit \(N\) tel que \(\frac{\pi^2}{6} - S_N \leqslant 10^{-3}\), et prédire l'ordre de grandeur du résultat (chapitre 13, exercice 9).

import numpy as np
cible = np.pi**2 / 6
S = 0
N = 0
while cible - S > 1e-3:
    N += 1
    S += 1 / N**2
print(N)

D'après le chapitre 13 (exercice 9), le reste \(R_N\) est compris entre \(\frac{1}{N+1}\) et \(\frac1N\) : il faut donc \(N \approx 1000\). Le programme affiche 1000 (exactement : le premier \(N\) tel que \(R_N \leqslant 10^{-3}\), soit 1000, car \(R_{999} > \frac{1}{1000} = 10^{-3} \geqslant R_{1000}\)).

Exercice 5 — Comparaison seuil / dichotomie (type concours)

Approfondissement

On cherche \(\alpha\) tel que \(\mathrm{e}^{\alpha} = 3\) (soit \(\alpha = \ln 3 \approx 1{,}0986\)), à \(10^{-8}\) près, sur \([1, 2]\).

  1. Combien d'itérations de dichotomie faut-il ?
  2. Écrire la fonction dichotomie correspondante.
  3. Pourquoi un balayage pas à pas (tester \(1 ;\ 1 + 10^{-8} ;\ 1 + 2\times10^{-8}\dots\)) serait-il inutilisable ?

1. Longueur initiale 1, précision \(10^{-8}\) : il faut \(k \geqslant \log_2(10^8) \approx 26{,}6\), soit 27 itérations.

import numpy as np

def f(x):
    return np.exp(x) - 3

a, b = 1, 2
while b - a > 1e-8:
    m = (a + b) / 2
    if f(a) * f(m) <= 0:
        b = m
    else:
        a = m
print((a + b) / 2)     # 1.09861229...

3. Le balayage exigerait jusqu'à \(10^8\) évaluations de \(f\) (complexité linéaire en \(\frac1\varepsilon\)), contre 27 pour la dichotomie (logarithmique) : plusieurs secondes ou minutes contre un temps imperceptible. C'est l'illustration type de l'intérêt d'un bon algorithme.

Exercice 6 — Synthèse : suite implicite (type concours)

Approfondissement

Pour \(n \geqslant 1\), on admet que l'équation \(x^n + x - 1 = 0\) possède une unique solution \(x_n\) dans \([0, 1]\). Écrire une fonction x(n, eps) qui approche \(x_n\) par dichotomie, puis un programme qui affiche \(x_1, x_2, \dots, x_{10}\). Que semble faire la suite \((x_n)\) ?

def x(n, eps):
    a, b = 0, 1
    while b - a > eps:
        m = (a + b) / 2
        if (a**n + a - 1) * (m**n + m - 1) <= 0:
            b = m
        else:
            a = m
    return (a + b) / 2

for n in range(1, 11):
    print(n, x(n, 1e-6))

Sorties : \(x_1 = 0{,}5\), \(x_2 \approx 0{,}618\), \(x_3 \approx 0{,}6823\), … , \(x_{10} \approx 0{,}869\) : la suite \((x_n)\) est croissante et semble tendre vers 1. (Preuve possible : \(f_n(x) = x^n + x - 1\) vérifie \(f_{n+1}(x_n) = x_n^{n+1} + x_n - 1 < x_n^n + x_n - 1 = 0\), donc \(x_{n+1} > x_n\) ; et \(x_n \to 1\) car pour tout \(c < 1\), \(f_n(c) \to c - 1 < 0\).)

Exercice 7 — Suite d'ordre 1

Application directe

Écrire u(n) pour \(u_0 = 5\), \(u_{n+1} = 2u_n - 3\). Que vaut u(3) ?

def u(n):
    x = 5
    for k in range(n):
        x = 2*x - 3
    return x

\(u_0 = 5, u_1 = 7, u_2 = 11, u_3 = 19\) : u(3) renvoie 19.

Exercice 8 — Seuil géométrique

Application directe

Écrire un programme donnant le plus petit \(n\) tel que \(2^n \geqslant 1000\).

x = 1        # 2**0
n = 0
while x < 1000:
    x = 2*x
    n = n + 1
print(n)

\(2^9 = 512 < 1000 \leqslant 1024 = 2^{10}\) : le programme affiche 10.

Exercice 9 — Suite d'ordre 2

Application directe

Écrire v(n) pour \(v_0 = 1\), \(v_1 = 1\), \(v_{n+2} = v_{n+1} + v_n\) (Fibonacci). Que vaut v(5) ?

def v(n):
    x, y = 1, 1
    for k in range(n):
        x, y = y, x + y
    return x

\(v_0, \dots, v_5 = 1, 1, 2, 3, 5, 8\) : v(5) renvoie 8. L'affectation simultanée est indispensable.

Exercice 10 — Prédire une accumulation

Application directe
x = 1
for k in range(4):
    x = x + 2*k
print(x)

\(k = 0 : x = 1\) ; \(k=1 : x = 3\) ; \(k=2 : x = 7\) ; \(k=3 : x = 13\). Affiche 13 (\(= 1 + 2(0+1+2+3)\)).

Exercice 11 — Seuil et suite arithmético-géométrique

Entraînement

La suite \(u_0 = 10\), \(u_{n+1} = \frac12 u_n + 1\) converge vers 2. Écrire un programme donnant le plus petit \(n\) tel que \(|u_n - 2| \leqslant 0{,}01\), et retrouver ce \(n\) par le calcul (\(u_n - 2 = 8\times(0{,}5)^n\)).

x = 10
n = 0
while abs(x - 2) > 0.01:
    x = 0.5*x + 1
    n = n + 1
print(n)

\(8\times(0{,}5)^n \leqslant 0{,}01 \iff (0{,}5)^n \leqslant 0{,}00125 \iff n \geqslant \frac{\ln 800}{\ln 2} \approx 9{,}64\) : le programme affiche 10.

Exercice 12 — Dichotomie pour \(\sqrt 2\)

Entraînement

Écrire racine2(eps) qui approche \(\sqrt2\) (solution de \(x^2 - 2 = 0\) sur \([1, 2]\)) par dichotomie.

def racine2(eps):
    a, b = 1, 2
    while b - a > eps:
        m = (a + b) / 2
        if m**2 <= 2:      # m est en dessous de racine(2)
            a = m
        else:
            b = m
    return (a + b) / 2      # racine2(1e-6) donne 1.41421...

Comme \(x \mapsto x^2\) est croissante, m**2 <= 2 signifie \(m \leqslant \sqrt2\) : on remonte la borne gauche.

Exercice 13 — Seuil sur la série harmonique

Entraînement

Écrire un programme donnant le plus petit \(N\) tel que \(H_N = \sum_{n=1}^{N}\frac1n \geqslant 5\). Quel ordre de grandeur attend-on ?

S = 0
N = 0
while S < 5:
    N = N + 1
    S = S + 1 / N
print(N)

Comme \(H_N \approx \ln N + \gamma\) (\(\gamma \approx 0{,}577\)), \(H_N \geqslant 5\) donne \(\ln N \gtrsim 4{,}42\), soit \(N\) de l'ordre de 83 : la croissance logarithmique rend ce seuil élevé.

Exercice 14 — Nombre d'itérations d'une dichotomie

Entraînement

Combien d'itérations de dichotomie faut-il pour atteindre une précision \(\varepsilon = 10^{-6}\) sur l'intervalle \([2, 5]\) ?

Après \(k\) itérations, la longueur de l'intervalle est \(\frac{5 - 2}{2^k} = \frac{3}{2^k}\). On veut \(\frac{3}{2^k} \leqslant 10^{-6}\), soit \(2^k \geqslant 3\times10^6\), \(k \geqslant \log_2(3\times10^6) \approx 21{,}5\) : il faut 22 itérations.

Exercice 15 — Stocker les termes d'une suite

Entraînement

Écrire termes(N) renvoyant la liste \([u_0, \dots, u_N]\) pour \(u_0 = 1\), \(u_{n+1} = 2u_n + 1\). Que vaut termes(3) ? Quelle formule close reconnaît-on ?

def termes(N):
    L = [1]
    for k in range(N):
        L.append(2*L[-1] + 1)
    return L

termes(3) renvoie [1, 3, 7, 15], soit \(u_n = 2^{n+1} - 1\) (chapitre 6).

Exercice 16 — Complexité quadratique (type concours)

Approfondissement

Que renvoie compte(n) ? Quelle est sa complexité en fonction de \(n\) ?

def compte(n):
    c = 0
    for i in range(n):
        for j in range(n):
            c = c + 1
    return c

La boucle interne fait \(n\) incréments, exécutée \(n\) fois : compte(n) renvoie \(n^2\). Le nombre d'opérations est proportionnel à \(n^2\) : complexité quadratique \(\mathcal O(n^2)\) (doubler \(n\) quadruple le temps).

Exercice 17 — Racine cubique par dichotomie (type concours)

Approfondissement

Écrire racine_cubique(A, eps) approchant \(\sqrt[3]{A}\) pour \(A \in [1, 8]\), par dichotomie sur \([1, 2]\) quand \(A = 7\).

def racine_cubique(A, eps):
    a, b = 1, 2
    while b - a > eps:
        m = (a + b) / 2
        if m**3 <= A:
            a = m
        else:
            b = m
    return (a + b) / 2

# racine_cubique(7, 1e-6) donne 1.91293...

La fonction \(x \mapsto x^3\) est croissante : m**3 <= A équivaut à \(m \leqslant \sqrt[3]{A}\), on remonte la borne gauche. Pour \(A = 7\), on trouve \(\sqrt[3]{7} \approx 1{,}913\).

Exercice 18 — Méthode de Héron (type concours)

Approfondissement

La suite \(x_0 = 2\), \(x_{n+1} = \frac12\left(x_n + \frac2{x_n}\right)\) converge vers \(\sqrt2\). Écrire heron(n) et détailler \(x_1, x_2, x_3\). Comparer la vitesse à la dichotomie.

def heron(n):
    x = 2.0
    for k in range(n):
        x = 0.5 * (x + 2/x)
    return x

\(x_1 = \frac12(2 + 1) = 1{,}5\) ; \(x_2 = \frac12(1{,}5 + 1{,}333\ldots) \approx 1{,}41667\) ; \(x_3 \approx 1{,}414216\). Le nombre de décimales exactes double à chaque étape (convergence quadratique) : 3 itérations donnent déjà \(\sqrt2\) à \(10^{-6}\) près, bien plus vite que la dichotomie (qui gagne 1 bit par tour).

Exercice 19 — Convergence du rapport de Fibonacci (type concours)

Approfondissement

Écrire un programme donnant le plus petit \(n\) tel que \(\left|\frac{F_{n+1}}{F_n} - \varphi\right| \leqslant 10^{-4}\), où \(\varphi = \frac{1 + \sqrt5}{2}\). Vers quoi tend ce rapport ?

phi = (1 + 5**0.5) / 2
a, b = 1, 1        # F_1, F_2
n = 1
while abs(b/a - phi) > 1e-4:
    a, b = b, a + b
    n = n + 1
print(n)

Le rapport \(\frac{F_{n+1}}{F_n}\) tend vers le nombre d'or \(\varphi \approx 1{,}618\). La convergence étant géométrique, le seuil est atteint pour un petit \(n\) (de l'ordre de 10).

Exercice 20 — Fonction mystère (type concours)

Approfondissement

Que renvoie mystere(20) ? Que calcule cette fonction, et quelle est sa complexité ?

def mystere(n):
    c = 0
    while n > 1:
        n = n // 2
        c = c + 1
    return c

Trace pour \(n = 20\) : \(20 \to 10 \to 5 \to 2 \to 1\), soit 4 divisions : renvoie 4.

La fonction compte combien de fois on peut diviser \(n\) par 2 avant d'atteindre 1 : elle calcule \(\lfloor \log_2 n \rfloor\) (ici \(2^4 = 16 \leqslant 20 < 32\)). Complexité logarithmique \(\mathcal O(\log n)\).
