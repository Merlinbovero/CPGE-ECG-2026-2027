Chapitre 6. Suites réelles

Les suites sont le cœur de l'analyse en ECG : suites usuelles à connaître parfaitement (arithmétiques, géométriques, arithmético-géométriques, récurrences linéaires d'ordre 2), puis étude de la convergence avec les grands théorèmes (limite monotone, gendarmes) et les croissances comparées.

1. Généralités : définitions, monotonie, bornes

Définition 6.1 — Suite, termes, monotonie, bornes

Une suite réelle est une application \(u : \mathbb{N} \to \mathbb{R}\), notée \((u_n)_{n \in \mathbb{N}}\). Le nombre \(u_n\) est le terme de rang (ou d'indice) \(n\). Lorsqu'une formule explicite donne \(u_n\) en fonction de \(n\), elle est appelée terme général. Le premier terme, souvent \(u_0\) ou \(u_1\), est le terme initial.

Rigueur : \(u_n\) est un nombre ; \((u_n)_n\) désigne la suite entière, donc une fonction. Une suite peut aussi n'être définie qu'à partir d'un rang \(n_0\).

La suite est :

  • croissante si \(\forall n,\ u_{n+1} \geqslant u_n\) (strictement si inégalité stricte) ; décroissante si \(u_{n+1} \leqslant u_n\) ; monotone si l'un des deux ;
  • majorée s'il existe \(M\) tel que \(\forall n,\ u_n \leqslant M\) ; minorée s'il existe \(m\) tel que \(\forall n,\ u_n \geqslant m\) ; bornée si les deux.
Quatre modes de définition d'une suite
  • Explicite : \(u_n=f(n)\), donc on calcule directement le terme de rang \(n\).
  • Par récurrence : on donne un ou plusieurs termes initiaux puis une relation utilisant un ou plusieurs termes précédents.
  • Implicite : chaque terme est défini comme solution d'une équation dépendant de \(n\).
  • Par imbrication : plusieurs suites sont définies conjointement et dépendent les unes des autres.

Ces quatre modes sont ceux du polycopié A1 ajouté à la bibliothèque le 5 septembre 2026.

Méthode — Étudier la monotonie
  • Signe de \(u_{n+1} - u_n\) : méthode universelle.
  • Quotient \(\frac{u_{n+1}}{u_n}\) comparé à 1 : seulement si tous les \(u_n\) sont strictement positifs.
  • Si \(u_n = f(n)\) avec \(f\) monotone sur \([0, +\infty[\) : la suite hérite de la monotonie de \(f\).

2. Suites arithmétiques et géométriques

Théorème 6.2 — Suites arithmétiques

\((u_n)\) est arithmétique de raison \(r\) si \(u_{n+1} = u_n + r\) pour tout \(n\). Alors :

\[ u_n = u_0 + nr = u_p + (n - p)r, \qquad \sum_{k=0}^{n} u_k = (n+1)\,\frac{u_0 + u_n}{2} \quad \text{(nombre de termes} \times \text{moyenne des extrêmes)}. \]

Théorème 6.3 — Suites géométriques

\((u_n)\) est géométrique de raison \(q\) si \(u_{n+1} = q\,u_n\) pour tout \(n\). Alors \(u_n = u_0\, q^n\), et si \(q \neq 1\) :

\[ \sum_{k=0}^{n} u_k = u_0\, \frac{1 - q^{n+1}}{1 - q}. \]

Comportement de \(q^n\) : si \(q > 1\), \(q^n \to +\infty\) ; si \(q = 1\), \(q^n = 1\) ; si \(|q| < 1\), \(q^n \to 0\) ; si \(q \leqslant -1\), \((q^n)\) diverge sans limite (oscillation).

3. Suites arithmético-géométriques

Théorème 6.4 — Suites arithmético-géométriques (méthode exigible)

Soit \((u_n)\) telle que \(u_{n+1} = a\,u_n + b\) avec \(a \neq 1\). Le point fixe \(\ell = \dfrac{b}{1-a}\) vérifie \(\ell = a\ell + b\). Alors la suite \(v_n = u_n - \ell\) est géométrique de raison \(a\), et :

\[ u_n = a^n(u_0 - \ell) + \ell. \]

Démonstration.

\(v_{n+1} = u_{n+1} - \ell = a u_n + b - (a\ell + b) = a(u_n - \ell) = a v_n\) : \((v_n)\) est géométrique de raison \(a\), donc \(v_n = a^n v_0\), d'où \(u_n = \ell + a^n(u_0 - \ell)\). ∎

Exemple rédigé. \(u_0 = 5\), \(u_{n+1} = \frac12 u_n + 3\). Point fixe : \(\ell = \frac{3}{1 - 1/2} = 6\). Alors \(u_n = 6 + \left(\frac12\right)^n(5 - 6) = 6 - \frac{1}{2^n}\). Comme \(\left|\frac12\right| < 1\), \(u_n \to 6\).

4. Récurrences linéaires d'ordre 2

Théorème 6.5 — Suites vérifiant \(u_{n+2} = a\,u_{n+1} + b\,u_n\)

On associe l'équation caractéristique \(x^2 = ax + b\), c'est-à-dire \(x^2 - ax - b = 0\), de discriminant \(\Delta\).

  • Si \(\Delta > 0\) (deux racines \(r_1 \neq r_2\)) : il existe \(\lambda, \mu \in \mathbb{R}\) tels que \(u_n = \lambda\, r_1^n + \mu\, r_2^n\) pour tout \(n\).
  • Si \(\Delta = 0\) (racine double \(r \neq 0\)) : il existe \(\lambda, \mu\) tels que \(u_n = (\lambda + \mu n)\, r^n\).

Les constantes \(\lambda, \mu\) se déterminent avec les conditions initiales \(u_0\) et \(u_1\). (Le cas \(\Delta < 0\) est hors programme en maths appliquées.)

Méthode — Résolution complète
  1. Écrire l'équation caractéristique et la résoudre.
  2. Écrire la forme générale de \(u_n\) selon le cas.
  3. Résoudre le système 2×2 donné par \(u_0\) et \(u_1\) pour trouver \(\lambda\) et \(\mu\).
  4. Vérifier avec \(u_2\).

Exemple rédigé. \(u_0 = 1\), \(u_1 = 8\), \(u_{n+2} = 4u_{n+1} - 4u_n\). Équation caractéristique : \(x^2 - 4x + 4 = 0\), soit \((x-2)^2 = 0\) : racine double \(r = 2\). Donc \(u_n = (\lambda + \mu n)2^n\). Conditions initiales : \(u_0 = \lambda = 1\) ; \(u_1 = (\lambda + \mu) \cdot 2 = 8\), donc \(\mu = 3\). Ainsi \(u_n = (1 + 3n)\,2^n\). Vérification : \(u_2 = 4 \times 8 - 4 \times 1 = 28\) et \((1 + 6) \times 4 = 28\) ✓.

5. Limite d'une suite

Définition 6.6 — Convergence

\((u_n)\) converge vers \(\ell \in \mathbb{R}\) si : \(\forall \varepsilon > 0,\ \exists n_0 \in \mathbb{N},\ \forall n \geqslant n_0,\ |u_n - \ell| \leqslant \varepsilon\). On note \(\lim\limits_{n \to +\infty} u_n = \ell\) ou \(u_n \to \ell\). La limite, si elle existe, est unique. Une suite qui ne converge pas diverge (vers \(\pm\infty\) ou sans limite).

\(u_n \to +\infty\) si : \(\forall A \in \mathbb{R},\ \exists n_0,\ \forall n \geqslant n_0,\ u_n \geqslant A\).

Théorème 6.7 — Opérations sur les limites

Si \(u_n \to \ell\) et \(v_n \to \ell'\) (limites finies) : \(u_n + v_n \to \ell + \ell'\), \(u_n v_n \to \ell\ell'\), et \(\frac{u_n}{v_n} \to \frac{\ell}{\ell'}\) si \(\ell' \neq 0\). Toute suite convergente est bornée.

Formes indéterminées à connaître : « \(+\infty - \infty\) », « \(0 \times \infty\) », « \(\frac{\infty}{\infty}\) », « \(\frac{0}{0}\) ». Elles exigent une transformation (factorisation du terme dominant, quantité conjuguée, croissances comparées…).

Méthode — Lever une indétermination \(\frac{\infty}{\infty}\)

Factoriser numérateur et dénominateur par leur terme dominant. Exemple :

\[ \frac{3n^2 - n + 1}{2n^2 + 5} = \frac{n^2\left(3 - \frac1n + \frac{1}{n^2}\right)}{n^2\left(2 + \frac{5}{n^2}\right)} \xrightarrow[n \to +\infty]{} \frac32. \]

6. Théorèmes de convergence

Théorème 6.8 — Limite monotone (fondamental)

Toute suite croissante et majorée converge. Toute suite décroissante et minorée converge. Une suite croissante non majorée tend vers \(+\infty\).

Attention : la limite d'une suite croissante majorée par \(M\) vérifie \(\ell \leqslant M\), mais n'est pas nécessairement \(M\).

Théorème 6.9 — Encadrement (« gendarmes ») et comparaison
  • Gendarmes : si \(v_n \leqslant u_n \leqslant w_n\) à partir d'un certain rang et si \(v_n \to \ell\) et \(w_n \to \ell\), alors \(u_n \to \ell\).
  • Comparaison : si \(u_n \geqslant v_n\) et \(v_n \to +\infty\), alors \(u_n \to +\infty\).
  • Passage à la limite : si \(u_n \leqslant v_n\) pour tout \(n\), et si les deux suites convergent, alors \(\lim u_n \leqslant \lim v_n\) (les inégalités strictes deviennent larges à la limite).
Méthode — Suites récurrentes \(u_{n+1} = f(u_n)\) : plan d'étude type
  1. Montrer (souvent par récurrence) que \((u_n)\) reste dans un intervalle stable \(I\).
  2. Étudier la monotonie : signe de \(u_{n+1} - u_n = f(u_n) - u_n\), souvent via le signe de \(f(x) - x\) sur \(I\).
  3. Conclure à la convergence par le théorème de la limite monotone.
  4. Identifier la limite : si \(f\) est continue, \(\ell\) vérifie \(f(\ell) = \ell\) (équation aux points fixes).

7. Croissances comparées et limites usuelles

Théorème 6.10 — Croissances comparées (à connaître par cœur)

Pour \(\alpha > 0\), \(\beta > 0\) et \(q > 1\) :

\[ \lim_{n \to +\infty} \frac{(\ln n)^\beta}{n^\alpha} = 0, \qquad \lim_{n \to +\infty} \frac{n^\alpha}{q^n} = 0, \qquad \lim_{n \to +\infty} \frac{q^n}{n!} = 0. \]

Hiérarchie : \(\ (\ln n)^\beta \ll n^\alpha \ll q^n \ll n!\) — « les logarithmes perdent contre les puissances, qui perdent contre les exponentielles, qui perdent contre la factorielle ».

Pièges classiques
  • Une suite bornée n'est pas forcément convergente : \(u_n = (-1)^n\) est bornée mais diverge.
  • Pour \(u_{n+1} = f(u_n)\), la limite éventuelle \(\ell\) vérifie \(f(\ell) = \ell\) — mais il faut d'abord prouver la convergence (bornes + monotonie) avant de « passer à la limite ».
  • Le quotient \(\frac{u_{n+1}}{u_n}\) ne s'utilise pour la monotonie que si les termes sont strictement positifs.
  • La limite d'une suite croissante majorée par \(M\) vérifie \(\ell \leqslant M\), sans être nécessairement égale à \(M\).

Fiche de révision condensée

L'essentiel à relire juste avant un DS ou une colle
  • Arithmétique : \(u_n = u_0 + nr\), \(\sum = (\text{nb termes})\times\frac{\text{1er}+\text{dernier}}{2}\). Géométrique : \(u_n = u_0 q^n\), \(\sum = u_0\frac{1-q^{n+1}}{1-q}\).
  • Arithmético-géométrique \(u_{n+1}=au_n+b\) : point fixe \(\ell=\frac{b}{1-a}\), \(v_n=u_n-\ell\) géométrique, \(u_n=\ell+a^n(u_0-\ell)\).
  • Ordre 2 \(u_{n+2}=au_{n+1}+bu_n\) : équation \(x^2=ax+b\) ; \(u_n=\lambda r_1^n+\mu r_2^n\) (ou \((\lambda+\mu n)r^n\) si racine double).
  • Croissances comparées : \(\frac{(\ln n)^\alpha}{n^\beta}\to 0\), \(\frac{n^\beta}{a^n}\to 0\) (\(a>1\)), \(\frac{a^n}{n!}\to 0\) : l'exponentielle bat la puissance, qui bat le logarithme, et la factorielle bat l'exponentielle.
  • Théorèmes : limite monotone (croissante majorée → converge), gendarmes, comparaison.
  • Comportement de \(q^n\) : \(\to 0\) si \(|q|<1\), \(\to +\infty\) si \(q>1\), diverge si \(q\leqslant -1\).

Exercices corrigés

Exercice 1 — Suites usuelles

Application directe

1. \((u_n)\) arithmétique avec \(u_3 = 11\) et \(u_7 = 23\). Donner \(r\), \(u_0\) et \(\sum_{k=0}^{20} u_k\).
2. \((v_n)\) géométrique de raison positive avec \(v_2 = 12\) et \(v_4 = 48\). Donner \(q\), \(v_0\) et \(\lim v_n\).

1. \(u_7 - u_3 = 4r = 12\), donc \(r = 3\) ; \(u_0 = u_3 - 3r = 2\). Alors \(u_{20} = 2 + 60 = 62\) et \(\sum_{k=0}^{20} u_k = 21 \times \frac{2 + 62}{2} = 21 \times 32 = 672\).

2. \(\frac{v_4}{v_2} = q^2 = 4\), donc \(q = 2\) (raison positive). \(v_0 = \frac{v_2}{q^2} = 3\). Comme \(q = 2 > 1\) et \(v_0 > 0\) : \(v_n = 3 \cdot 2^n \to +\infty\).

Exercice 2 — Limites par opérations

Application directe

Déterminer les limites : 1. \(u_n = \dfrac{2n^3 - n}{n^3 + n^2 + 1}\) ;   2. \(v_n = \dfrac{n^2 + 1}{n + 3}\) ;   3. \(w_n = \sqrt{n+1} - \sqrt n\).

1. Factorisation par \(n^3\) : \(u_n = \frac{2 - 1/n^2}{1 + 1/n + 1/n^3} \to 2\).

2. \(v_n = \frac{n^2(1 + 1/n^2)}{n(1 + 3/n)} = n \cdot \frac{1 + 1/n^2}{1 + 3/n} \to +\infty\).

3. Forme \(\infty - \infty\) : quantité conjuguée. \(w_n = \frac{(n+1) - n}{\sqrt{n+1} + \sqrt n} = \frac{1}{\sqrt{n+1} + \sqrt n} \to 0\).

Exercice 3 — Arithmético-géométrique

Application directe

Soit \(u_0 = 0\) et \(u_{n+1} = 3u_n + 4\). Exprimer \(u_n\) en fonction de \(n\) et donner sa limite.

Point fixe : \(\ell = 3\ell + 4\) donne \(\ell = -2\). Posons \(v_n = u_n + 2\) : \(v_{n+1} = u_{n+1} + 2 = 3u_n + 6 = 3v_n\) : géométrique de raison 3, \(v_0 = 2\).

Donc \(v_n = 2 \cdot 3^n\) et \(u_n = 2 \cdot 3^n - 2\). Vérification : \(u_1 = 4\) et \(2 \times 3 - 2 = 4\) ✓. Comme \(3 > 1\) : \(u_n \to +\infty\).

Exercice 4 — Récurrence linéaire d'ordre 2

Entraînement

Soit \(u_0 = 3\), \(u_1 = 4\) et \(u_{n+2} = \dfrac{5u_{n+1} - 2u_n}{2}\) (soit \(u_{n+2} = \frac52 u_{n+1} - u_n\)). Exprimer \(u_n\) et déterminer \(\lim u_n\).

Équation caractéristique : \(x^2 - \frac52 x + 1 = 0\), soit \(2x^2 - 5x + 2 = 0\) : \(\Delta = 25 - 16 = 9\), racines \(x = \frac{5 \pm 3}{4}\), soit \(r_1 = 2\) et \(r_2 = \frac12\).

Donc \(u_n = \lambda\, 2^n + \mu \left(\frac12\right)^n\). Conditions initiales : \(\lambda + \mu = 3\) et \(2\lambda + \frac{\mu}{2} = 4\). De la première, \(\mu = 3 - \lambda\) ; en reportant : \(2\lambda + \frac{3 - \lambda}{2} = 4\), soit \(4\lambda + 3 - \lambda = 8\) : \(\lambda = \frac53\), \(\mu = \frac43\).

\[ u_n = \frac53\, 2^n + \frac43 \left(\frac12\right)^n. \]

Vérification : \(u_2 = \frac52 \times 4 - 3 = 7\) et \(\frac53 \times 4 + \frac43 \times \frac14 = \frac{20}{3} + \frac13 = 7\) ✓. Comme \(2 > 1\) et \(\lambda > 0\) : \(u_n \to +\infty\).

Exercice 5 — Gendarmes

Entraînement

Déterminer la limite de \(u_n = \dfrac{n + (-1)^n}{n + 2}\), puis celle de \(v_n = \dfrac{\cos n + 2n}{n}\) (on rappelle \(-1 \leqslant \cos n \leqslant 1\)).

Pour \((u_n)\) : \(-1 \leqslant (-1)^n \leqslant 1\) donne \(\frac{n-1}{n+2} \leqslant u_n \leqslant \frac{n+1}{n+2}\). Les deux bornes tendent vers 1 (factoriser par \(n\)), donc par le théorème des gendarmes, \(u_n \to 1\).

Pour \((v_n)\) : \(v_n = \frac{\cos n}{n} + 2\). Or \(\left|\frac{\cos n}{n}\right| \leqslant \frac1n \to 0\), donc \(\frac{\cos n}{n} \to 0\) (gendarmes) et \(v_n \to 2\).

Exercice 6 — Croissances comparées

Entraînement

Déterminer les limites : 1. \(\dfrac{n^{10}}{2^n}\) ;   2. \(\dfrac{3^n}{n!}\) ;   3. \(\dfrac{n^2 + 2^n}{3^n}\) ;   4. \(n^2 \left(\dfrac{1}{2}\right)^n - \dfrac{(\ln n)^3}{\sqrt n}\).

  1. \(\to 0\) : puissance contre géométrique de raison \(2 > 1\).
  2. \(\to 0\) : géométrique contre factorielle.
  3. \(\frac{n^2 + 2^n}{3^n} = \frac{n^2}{3^n} + \left(\frac23\right)^n \to 0 + 0 = 0\).
  4. \(n^2(\frac12)^n = \frac{n^2}{2^n} \to 0\) et \(\frac{(\ln n)^3}{\sqrt n} = \frac{(\ln n)^3}{n^{1/2}} \to 0\) (croissances comparées avec \(\alpha = \frac12\)). Donc la différence tend vers \(0\).

Exercice 7 — Suite récurrente \(u_{n+1} = f(u_n)\)

Approfondissement

Soit \(u_0 = 0\) et \(u_{n+1} = \sqrt{u_n + 2}\).

  1. Montrer que pour tout \(n\), \(0 \leqslant u_n \leqslant 2\).
  2. Montrer que \((u_n)\) est croissante.
  3. En déduire que \((u_n)\) converge et déterminer sa limite.

1. Récurrence. \(u_0 = 0 \in [0, 2]\) ✓. Si \(0 \leqslant u_n \leqslant 2\), alors \(2 \leqslant u_n + 2 \leqslant 4\), donc (croissance de la racine) \(\sqrt2 \leqslant u_{n+1} \leqslant 2\), et en particulier \(0 \leqslant u_{n+1} \leqslant 2\). ✓ ∎

2. \(u_{n+1} - u_n = \sqrt{u_n + 2} - u_n\). Étudions \(g(x) = \sqrt{x+2} - x\) sur \([0,2]\) : \(g(x) \geqslant 0 \iff \sqrt{x+2} \geqslant x \iff x + 2 \geqslant x^2\) (les deux membres sont positifs sur \([0,2]\)) \(\iff x^2 - x - 2 \leqslant 0 \iff (x-2)(x+1) \leqslant 0\), vrai pour \(x \in [-1, 2]\), donc sur \([0,2]\). Ainsi \(u_{n+1} \geqslant u_n\) : \((u_n)\) est croissante. ∎

3. Croissante et majorée par 2 : \((u_n)\) converge vers un réel \(\ell \in [0,2]\). La fonction \(x \mapsto \sqrt{x+2}\) étant continue, \(\ell\) vérifie \(\ell = \sqrt{\ell + 2}\), soit \(\ell^2 = \ell + 2\) avec \(\ell \geqslant 0\) : \(\ell^2 - \ell - 2 = (\ell - 2)(\ell + 1) = 0\), donc \(\ell = 2\) (la racine \(-1\) est exclue). Conclusion : \(u_n \to 2\).

Exercice 8 — Étude complète type concours

Approfondissement

Un capital de 1 000 € est placé au taux mensuel de 1 %. Chaque fin de mois, après versement des intérêts, on retire 15 €. Notons \(C_n\) le capital après \(n\) mois : \(C_0 = 1000\) et \(C_{n+1} = 1{,}01\,C_n - 15\).

  1. Exprimer \(C_n\) en fonction de \(n\).
  2. Le capital augmente-t-il ou diminue-t-il ? Quelle est sa limite ?
  3. Même question si l'on retire 5 € par mois au lieu de 15 €.

1. Suite arithmético-géométrique, point fixe \(\ell = \frac{-15}{1 - 1{,}01} = \frac{-15}{-0{,}01} = 1500\). Donc :

\[ C_n = 1500 + (1000 - 1500)(1{,}01)^n = 1500 - 500 \times 1{,}01^n. \]

2. \(1{,}01^n\) croît vers \(+\infty\), donc \(C_n\) décroît et \(C_n \to -\infty\) : le capital s'épuise (le retrait de 15 € dépasse les intérêts mensuels, au plus \(0{,}01 \times 1500 = 15\) € atteints seulement au point fixe). Le capital devient négatif quand \(1{,}01^n > 3\), soit \(n > \frac{\ln 3}{\ln 1{,}01} \approx 110{,}4\) : au bout de 111 mois (environ 9 ans et 3 mois).

3. Point fixe : \(\ell = \frac{-5}{-0{,}01} = 500\), et \(C_n = 500 + 500 \times 1{,}01^n\) : le capital croît vers \(+\infty\) (le retrait de 5 € est inférieur aux intérêts, environ 10 € le premier mois).

Exercice 9 — Suites adjacentes de moyennes (type concours)

Approfondissement

Soient \(0 < a < b\). On définit \(u_0 = a\), \(v_0 = b\), puis \(u_{n+1} = \sqrt{u_n v_n}\) (moyenne géométrique) et \(v_{n+1} = \dfrac{u_n + v_n}{2}\) (moyenne arithmétique).

  1. Montrer que pour tout \(n\), \(0 < u_n \leqslant v_n\).
  2. Montrer que \((u_n)\) est croissante et \((v_n)\) décroissante.
  3. Montrer que \(v_{n+1} - u_{n+1} \leqslant \frac12 (v_n - u_n)\), puis que les deux suites convergent vers la même limite.

1. Récurrence : vrai pour \(n = 0\). Si \(0 < u_n \leqslant v_n\), alors \(u_{n+1} = \sqrt{u_n v_n} > 0\), \(v_{n+1} > 0\), et par l'inégalité arithmético-géométrique (chapitre 3, exercice 7) : \(\sqrt{u_n v_n} \leqslant \frac{u_n + v_n}{2}\), soit \(u_{n+1} \leqslant v_{n+1}\). ∎

2. \(u_{n+1} = \sqrt{u_n v_n} \geqslant \sqrt{u_n \cdot u_n} = u_n\) (car \(v_n \geqslant u_n > 0\)) : \((u_n)\) croît. \(v_{n+1} = \frac{u_n + v_n}{2} \leqslant \frac{v_n + v_n}{2} = v_n\) : \((v_n)\) décroît. ∎

3. \(v_{n+1} - u_{n+1} \leqslant v_{n+1} - u_n \) ? Procédons directement :

\[ v_{n+1} - u_{n+1} = \frac{u_n + v_n}{2} - \sqrt{u_n v_n} = \frac{(\sqrt{v_n} - \sqrt{u_n})^2}{2} = \frac{(\sqrt{v_n} - \sqrt{u_n})(\sqrt{v_n} - \sqrt{u_n})}{2}. \]

Or \(\sqrt{v_n} - \sqrt{u_n} = \frac{v_n - u_n}{\sqrt{v_n} + \sqrt{u_n}} \leqslant \frac{v_n - u_n}{\sqrt{v_n}}\) et \(\sqrt{v_n} - \sqrt{u_n} \leqslant \sqrt{v_n}\), donc :

\[ v_{n+1} - u_{n+1} \leqslant \frac12 \cdot \sqrt{v_n} \cdot \frac{v_n - u_n}{\sqrt{v_n}} = \frac{v_n - u_n}{2}. \]

Par récurrence immédiate, \(0 \leqslant v_n - u_n \leqslant \frac{b - a}{2^n} \to 0\). \((u_n)\) est croissante et majorée par \(v_0 = b\) (car \(u_n \leqslant v_n \leqslant b\)) : elle converge vers \(\ell\). \((v_n)\) est décroissante minorée par \(a\) : elle converge vers \(\ell'\). Et \(v_n - u_n \to 0\) donne \(\ell' = \ell\) : les deux suites convergent vers la même limite (appelée moyenne arithmético-géométrique de \(a\) et \(b\)). ∎

Exercice 10 — Limites de suites géométriques

Application directe

Déterminer la limite (ou la nature) de : 1. \(u_n = \left(\dfrac23\right)^n\) ;   2. \(v_n = \left(-\dfrac12\right)^n\) ;   3. \(w_n = \dfrac{3^n}{2^n}\) ;   4. \(t_n = (-2)^n\).

1. \(|q| = \frac23 < 1\) : \(u_n \to 0\).   2. \(|q| = \frac12 < 1\) : \(v_n \to 0\).   3. \(w_n = \left(\frac32\right)^n\) avec \(q = \frac32 > 1\) : \(w_n \to +\infty\).   4. \(q = -2 \leqslant -1\) : \((t_n)\) diverge sans limite (oscille en changeant de signe, \(|t_n| \to +\infty\)).

Exercice 11 — Sommes de suites usuelles

Application directe

Calculer, pour \(n \in \mathbb{N}\) : 1. \(S = \displaystyle\sum_{k=0}^{n} (3 + 2k)\) ;   2. \(T = \displaystyle\sum_{k=0}^{n} 5 \left(\dfrac12\right)^k\).

1. Suite arithmétique (raison 2), \(n+1\) termes, de premier terme 3 et dernier \(3 + 2n\) : \(S = (n+1)\dfrac{3 + (3+2n)}{2} = (n+1)(n+3)\).

2. Suite géométrique de raison \(\frac12\) : \(T = 5 \cdot \dfrac{1 - (1/2)^{n+1}}{1 - 1/2} = 10\left(1 - \dfrac{1}{2^{n+1}}\right) = 10 - \dfrac{5}{2^n}\).

Exercice 12 — Arithmético-géométrique

Application directe

Soit \(u_0 = 1\) et \(u_{n+1} = \dfrac12 u_n + 3\). Exprimer \(u_n\) et déterminer sa limite.

Point fixe : \(\ell = \dfrac{3}{1 - 1/2} = 6\). La suite \(v_n = u_n - 6\) est géométrique de raison \(\frac12\) : \(v_n = (u_0 - 6)\left(\frac12\right)^n = -5 \left(\frac12\right)^n\). Donc \(u_n = 6 - \dfrac{5}{2^n}\). Comme \(\frac12 < 1\), \(u_n \to 6\).

Exercice 13 — Récurrence linéaire d'ordre 2

Entraînement

Soit \(u_0 = 0\), \(u_1 = 1\) et \(u_{n+2} = 5u_{n+1} - 6u_n\). Exprimer \(u_n\) en fonction de \(n\).

Équation caractéristique : \(x^2 - 5x + 6 = 0\), racines \(r_1 = 2\), \(r_2 = 3\). Donc \(u_n = \lambda\, 2^n + \mu\, 3^n\). Conditions initiales : \(u_0 = \lambda + \mu = 0\) et \(u_1 = 2\lambda + 3\mu = 1\). De la première \(\lambda = -\mu\), d'où \(-2\mu + 3\mu = \mu = 1\), donc \(\mu = 1\), \(\lambda = -1\).

\(u_n = 3^n - 2^n\). Vérification : \(u_2 = 9 - 4 = 5 = 5 \times 1 - 6 \times 0\) ✓.

Exercice 14 — Encadrement (gendarmes)

Entraînement

Déterminer la limite de \(u_n = \dfrac{3n + (-1)^n}{n + 2}\).

Comme \(-1 \leqslant (-1)^n \leqslant 1\), on encadre (le dénominateur \(n + 2 > 0\)) :

\[ \frac{3n - 1}{n + 2} \leqslant u_n \leqslant \frac{3n + 1}{n + 2}. \]

Les deux bornes tendent vers 3 (quotient de polynômes de même degré, rapport des coefficients dominants). Par le théorème des gendarmes, \(u_n \to 3\). ∎

Exercice 15 — Croissances comparées

Entraînement

Déterminer la limite de : 1. \(\dfrac{n^2}{2^n}\) ;   2. \(\dfrac{\ln n}{\sqrt n}\) ;   3. \(\dfrac{n \cdot 3^n}{4^n}\) ;   4. \(\dfrac{\mathrm{e}^n}{n^{10}}\).

1. L'exponentielle \(2^n\) l'emporte sur la puissance \(n^2\) : \(\dfrac{n^2}{2^n} \to 0\).

2. \(\sqrt n = n^{1/2}\) l'emporte sur \(\ln n\) : \(\dfrac{\ln n}{\sqrt n} \to 0\).

3. \(\dfrac{n \cdot 3^n}{4^n} = n \left(\dfrac34\right)^n \to 0\) (l'exponentielle \((3/4)^n \to 0\) l'emporte sur \(n\)).

4. \(\mathrm{e}^n\) (exponentielle de base \(\mathrm{e} > 1\)) l'emporte sur \(n^{10}\) : \(\dfrac{\mathrm{e}^n}{n^{10}} \to +\infty\).

Exercice 16 — Somme et limite monotone

Entraînement

Soit \(u_n = \displaystyle\sum_{k=1}^{n} \dfrac{1}{k^2}\). Montrer que \((u_n)\) est croissante et majorée par 2, et conclure quant à sa convergence.

Croissance : \(u_{n+1} - u_n = \dfrac{1}{(n+1)^2} > 0\).

Majoration : pour \(k \geqslant 2\), \(\dfrac{1}{k^2} \leqslant \dfrac{1}{k(k-1)} = \dfrac{1}{k-1} - \dfrac1k\). Donc :

\[ u_n = 1 + \sum_{k=2}^{n} \frac{1}{k^2} \leqslant 1 + \sum_{k=2}^{n}\left(\frac{1}{k-1} - \frac1k\right) = 1 + \left(1 - \frac1n\right) = 2 - \frac1n < 2. \]

\((u_n)\) est croissante et majorée par 2 : d'après le théorème de la limite monotone, elle converge (vers une limite \(\leqslant 2\) ; on sait par ailleurs qu'elle vaut \(\frac{\pi^2}{6} \approx 1{,}64\)). ∎

Exercice 17 — Suite récurrente \(u_{n+1} = \sqrt{2u_n}\)

Approfondissement

Soit \(u_0 = 1\) et \(u_{n+1} = \sqrt{2u_n}\). 1. Montrer que \(0 < u_n \leqslant 2\) pour tout \(n\). 2. Montrer que \((u_n)\) est croissante. 3. En déduire qu'elle converge et déterminer sa limite.

1. Par récurrence : \(u_0 = 1 \in \,]0, 2]\). Si \(0 < u_n \leqslant 2\), alors \(0 < 2u_n \leqslant 4\), donc \(0 < u_{n+1} = \sqrt{2u_n} \leqslant \sqrt4 = 2\).

2. Les termes étant positifs, comparons les carrés : \(u_{n+1}^2 - u_n^2 = 2u_n - u_n^2 = u_n(2 - u_n) \geqslant 0\) (car \(0 < u_n \leqslant 2\)). Donc \(u_{n+1} \geqslant u_n\) : la suite est croissante.

3. Croissante et majorée par 2, elle converge vers une limite \(\ell \in \,]0, 2]\). En passant à la limite dans \(u_{n+1} = \sqrt{2u_n}\) (fonction \(x \mapsto \sqrt{2x}\) continue) : \(\ell = \sqrt{2\ell}\), soit \(\ell^2 = 2\ell\), donc \(\ell = 2\) (car \(\ell > 0\)). Ainsi \(u_n \to 2\). ∎

Exercice 18 — La suite des \(\sum 1/k!\)

Approfondissement

Soit \(u_n = \displaystyle\sum_{k=0}^{n} \dfrac{1}{k!}\). 1. Montrer que \(k! \geqslant 2^{k-1}\) pour \(k \geqslant 1\). 2. En déduire que \((u_n)\) est croissante et majorée par 3, donc convergente.

1. Par récurrence : \(1! = 1 = 2^0\). Si \(k! \geqslant 2^{k-1}\), alors \((k+1)! = (k+1)\,k! \geqslant 2 \cdot 2^{k-1} = 2^k\) (car \(k + 1 \geqslant 2\)). ∎

2. \(u_{n+1} - u_n = \frac{1}{(n+1)!} > 0\) : croissante. Majoration :

\[ u_n = 1 + \sum_{k=1}^{n} \frac{1}{k!} \leqslant 1 + \sum_{k=1}^{n} \frac{1}{2^{k-1}} = 1 + \frac{1 - (1/2)^n}{1 - 1/2} = 1 + 2\left(1 - \frac{1}{2^n}\right) < 3. \]

Croissante et majorée par 3, \((u_n)\) converge (sa limite est le nombre \(\mathrm{e} \approx 2{,}718\)). ∎

Exercice 19 — Suites adjacentes (série alternée, type concours)

Approfondissement

Soit \(a_n = \displaystyle\sum_{k=1}^{n} \dfrac{(-1)^{k+1}}{k}\) (sommes partielles de la série harmonique alternée). Montrer que \((a_{2n})\) et \((a_{2n+1})\) sont adjacentes, et en déduire que \((a_n)\) converge.

\((a_{2n})\) croissante : \(a_{2n+2} - a_{2n} = \dfrac{1}{2n+1} - \dfrac{1}{2n+2} > 0\).

\((a_{2n+1})\) décroissante : \(a_{2n+3} - a_{2n+1} = -\dfrac{1}{2n+2} + \dfrac{1}{2n+3} < 0\).

Différence \(\to 0\) : \(a_{2n+1} - a_{2n} = \dfrac{1}{2n+1} \xrightarrow[n \to +\infty]{} 0\).

Les deux suites sont donc adjacentes : elles convergent vers une même limite \(\ell\). Comme les termes d'indices pairs et impairs de \((a_n)\) convergent tous deux vers \(\ell\), la suite \((a_n)\) converge vers \(\ell\) (sa valeur est \(\ln 2\)). ∎

Exercice 20 — Limite de \(n!/n^n\) (type concours)

Approfondissement

Montrer que \(\displaystyle\frac{n!}{n^n} \xrightarrow[n \to +\infty]{} 0\).

On écrit le quotient comme un produit de facteurs :

\[ \frac{n!}{n^n} = \frac{1 \times 2 \times \cdots \times n}{n \times n \times \cdots \times n} = \frac1n \times \frac2n \times \cdots \times \frac nn. \]

Chaque facteur \(\frac kn\) (pour \(1 \leqslant k \leqslant n\)) est compris entre 0 et 1, donc le produit des facteurs d'indices \(k \geqslant 2\) est \(\leqslant 1\). En ne gardant que le premier facteur :

\[ 0 < \frac{n!}{n^n} = \frac1n \times \underbrace{\frac2n \times \cdots \times \frac nn}_{\leqslant\, 1} \leqslant \frac1n. \]

Comme \(\frac1n \to 0\), le théorème des gendarmes donne \(\dfrac{n!}{n^n} \to 0\). ∎
