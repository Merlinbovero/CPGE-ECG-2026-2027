Informatique I2. Listes et manipulation de données

La liste est la structure de données de base : stocker les termes d'une suite, les résultats d'une simulation, une série statistique. Indexation, slicing, méthodes et listes en compréhension.

TP tout au long de l'année
Objectifs de la fiche (programme officiel)
  • Créer, indexer (indices de 0 à \(n-1\), indices négatifs) et modifier une liste.
  • Parcourir une liste par éléments (for x in L) ou par indices (for i in range(len(L))), construire avec append.
  • Maîtriser le slicing L[a:b:p] (borne droite exclue).
  • Utiliser les fonctions/méthodes usuelles (sum, max, min, len, sorted, append, in).
  • Écrire des listes en compréhension et stocker les termes d'une suite ou d'une simulation.

1. Créer et indexer une liste

L = [4, 7, 1, 9]
print(L[0])      # 4  (les indices commencent à 0 !)
print(L[3])      # 9  (dernier élément, d'indice len(L) - 1)
print(L[-1])     # 9  (indice négatif : on compte depuis la fin)
print(len(L))    # 4  (longueur)
L[1] = 5         # modification : L vaut [4, 5, 1, 9]
M = [0] * 6      # [0, 0, 0, 0, 0, 0] : liste de six zéros
N = list(range(5))   # [0, 1, 2, 3, 4]
Piège n°1 du concours

Une liste de longueur \(n\) a ses indices de 0 à \(n-1\). L[n] provoque une erreur IndexError. Le \(k\)-ième terme d'une suite \(u_0, u_1, \dots\) stockée dans L est L[k] — mais si la suite commence à \(u_1\), il y a un décalage à gérer.

2. Parcourir une liste

L = [12, 8, 15, 3]

# Parcours par éléments
S = 0
for x in L:
    S += x
print(S)              # 38

# Parcours par indices (utile pour comparer des positions)
for i in range(len(L)):
    print(i, L[i])

# Construire en ajoutant au fur et à mesure
carres = []
for k in range(1, 6):
    carres.append(k**2)
print(carres)         # [1, 4, 9, 16, 25]

3. Slicing (tranches)

L = [10, 11, 12, 13, 14, 15]
print(L[1:4])    # [11, 12, 13]  (borne droite exclue)
print(L[:3])     # [10, 11, 12]  (depuis le début)
print(L[3:])     # [13, 14, 15]  (jusqu'à la fin)
print(L[::2])    # [10, 12, 14]  (un élément sur deux)
print(L[::-1])   # [15, 14, 13, 12, 11, 10]  (liste renversée)

4. Méthodes et fonctions utiles

ExpressionEffet
L.append(x)ajoute x en fin de liste
sum(L), max(L), min(L)somme, maximum, minimum
sorted(L)renvoie une copie triée (croissante)
L.count(x)nombre d'occurrences de x
x in Ltest d'appartenance (booléen)
L1 + L2concaténation

Moyenne d'une série : sum(L) / len(L). Les chaînes de caractères se manipulent comme des listes (indexation, slicing, len), mais sont non modifiables.

5. Listes en compréhension

carres = [k**2 for k in range(1, 6)]          # [1, 4, 9, 16, 25]
pairs  = [x for x in range(20) if x % 2 == 0]  # [0, 2, 4, ..., 18]
u = [3 * 0.5**n for n in range(4)]             # [3.0, 1.5, 0.75, 0.375]

Syntaxe compacte équivalente à une boucle for + append ; très fréquente dans les corrigés de concours.

Fiche de révision condensée
  • Indices : L[0] premier, L[-1] dernier, L[k] = \((k+1)\)-ème ; len(L) longueur.
  • Création : [0]*n (n zéros), list(range(n)), L.append(x).
  • Parcours : for x in L (éléments) ou for i in range(len(L)) (indices).
  • Slicing : L[a:b] (b exclu), L[::2] (un sur deux), L[::-1] (renversée).
  • Outils : sum(L), max(L), min(L), sorted(L), L.count(x), x in L.
  • Moyenne : sum(L)/len(L).
  • Compréhension : [f(k) for k in range(n) if cond].
  • Piège : L[len(L)] lève IndexError ; attention au décalage rang↔indice.

Exercices corrigés

Exercice 1 — Prédire la sortie

Application directe
L = [2, 5, 8, 11, 14]
print(L[2], L[-2])
print(L[1:3])
print(len(L[1:]))
M = [x % 3 for x in L]
print(M)

8 11 (indices 2 et −2) ; [5, 8] (indices 1 et 2) ; 4 (la tranche L[1:] a 4 éléments) ; [2, 2, 2, 2, 2] (tous les termes valent 2 modulo 3 : \(2, 5, 8, 11, 14 \equiv 2 \pmod 3\)).

Exercice 2 — Statistiques sur une liste

Application directe

Écrire des fonctions moyenne(L) et variance(L) (formule \(s^2 = \frac1n\sum x_i^2 - \bar x^2\)), sans utiliser de bibliothèque.

def moyenne(L):
    return sum(L) / len(L)

def variance(L):
    m = moyenne(L)
    S2 = 0
    for x in L:
        S2 += x**2
    return S2 / len(L) - m**2

# variance([8, 12, 9, 15, 11, 12, 10, 12, 6, 15]) renvoie 7.4
# (cf. chapitre 17, exercice 1)

Exercice 3 — Stocker les termes d'une suite

Entraînement

La suite \((u_n)\) vérifie \(u_0 = 2\) et \(u_{n+1} = \frac12 u_n + 3\). Écrire une fonction termes(N) qui renvoie la liste \([u_0, u_1, \dots, u_N]\). Que vaut termes(3) ?

def termes(N):
    L = [2]                       # u_0
    for k in range(N):
        L.append(0.5 * L[-1] + 3) # u_{k+1} à partir du dernier terme
    return L

termes(3) renvoie [2, 4.0, 5.0, 5.5] (en effet \(u_1 = 4\), \(u_2 = 5\), \(u_3 = 5{,}5\) ; la suite converge vers le point fixe 6, cf. chapitre 6).

Exercice 4 — Maximum « à la main »

Entraînement

Sans utiliser max, écrire une fonction maximum(L) qui renvoie le plus grand élément d'une liste non vide, et une fonction indice_max(L) qui renvoie l'indice de la première occurrence du maximum.

def maximum(L):
    m = L[0]
    for x in L:
        if x > m:
            m = x
    return m

def indice_max(L):
    im = 0
    for i in range(1, len(L)):
        if L[i] > L[im]:
            im = i
    return im
# maximum([3, 9, 2, 9]) renvoie 9 ; indice_max([3, 9, 2, 9]) renvoie 1

Schéma « accumulateur initialisé au premier élément » : à connaître, il tombe régulièrement (recherche du max d'une simulation, du premier rang où une suite dépasse un seuil…).

Exercice 5 — Compter avec une condition (type concours)

Approfondissement

On dispose d'une liste notes de \(n\) notes. Écrire un programme qui calcule la fréquence des notes supérieures ou égales à 10, puis une fonction quartiles(L) qui renvoie le couple \((Q_1, Q_3)\) défini par : \(Q_1\) = plus petite valeur telle qu'au moins 25 % des valeurs lui soient inférieures ou égales (position \(\lceil n/4 \rceil\) dans la liste triée), et \(Q_3\) analogue avec 75 %.

def freq_admis(notes):
    c = 0
    for x in notes:
        if x >= 10:
            c += 1
    return c / len(notes)

def quartiles(L):
    T = sorted(L)
    n = len(T)
    i1 = (n + 3) // 4        # équivaut à ceil(n/4) pour n entier
    i3 = (3*n + 3) // 4      # équivaut à ceil(3n/4)
    return T[i1 - 1], T[i3 - 1]   # -1 : passage rang -> indice

# quartiles([6, 8, 9, 10, 11, 12, 12, 12, 15, 15]) renvoie (9, 12) :
# n = 10, rangs 3 et 8 de la liste triée.

Le point délicat est le passage du rang (1 à \(n\)) à l'indice Python (0 à \(n-1\)) : source classique d'erreurs d'« off by one ».

Exercice 6 — Fibonacci et listes (type concours)

Approfondissement

La suite de Fibonacci vérifie \(F_0 = 0\), \(F_1 = 1\), \(F_{n+2} = F_{n+1} + F_n\).

  1. Écrire fibo(n) qui renvoie la liste \([F_0, \dots, F_n]\).
  2. Écrire un programme qui affiche le plus petit \(n\) tel que \(F_n > 10^6\), et prédire l'ordre de grandeur du résultat sachant \(F_n \approx \frac{\varphi^n}{\sqrt5}\) avec \(\varphi \approx 1{,}618\).
def fibo(n):
    L = [0, 1]
    for k in range(n - 1):
        L.append(L[-1] + L[-2])
    return L                      # fibo(6) renvoie [0, 1, 1, 2, 3, 5, 8]

a, b = 0, 1
n = 1
while b <= 10**6:
    a, b = b, a + b
    n += 1
print(n)

Estimation : \(\frac{\varphi^n}{\sqrt5} > 10^6\) ⟺ \(n > \frac{\ln(10^6\sqrt5)}{\ln\varphi} \approx \frac{14{,}62}{0{,}481} \approx 30{,}4\). Le programme affiche 31 (\(F_{31} = 1\,346\,269 > 10^6 > F_{30} = 832\,040\)).

Exercice 8 — Compter les positifs

Application directe

Écrire une fonction nb_positifs(L) qui renvoie le nombre d'éléments strictement positifs.

def nb_positifs(L):
    c = 0
    for x in L:
        if x > 0:
            c = c + 1
    return c          # nb_positifs([-2, 3, 0, 5, -1]) renvoie 2

Exercice 11 — Produit scalaire

Entraînement

Écrire produit_scalaire(U, V) qui renvoie \(\sum_i U_i V_i\) pour deux listes de même longueur.

def produit_scalaire(U, V):
    s = 0
    for i in range(len(U)):
        s = s + U[i] * V[i]
    return s          # produit_scalaire([1, 2, 3], [4, 5, 6]) renvoie 32

Ici il faut parcourir par indices (on lit deux listes en parallèle).

Exercice 12 — Sommes cumulées

Entraînement

Écrire cumul(L) qui renvoie la liste des sommes partielles : cumul([2, 3, 5, 1]) doit donner [2, 5, 10, 11].

def cumul(L):
    C = [L[0]]
    for i in range(1, len(L)):
        C.append(C[-1] + L[i])
    return C

Chaque terme réutilise le précédent (C[-1]), ce qui évite de tout resommer à chaque étape.

Exercice 13 — Recherche d'un élément

Entraînement

Écrire recherche(L, x) qui renvoie l'indice de la première occurrence de x, ou -1 si x est absent.

def recherche(L, x):
    for i in range(len(L)):
        if L[i] == x:
            return i          # trouvé : on sort aussitôt
    return -1                 # parcours terminé sans succès

recherche([4, 7, 2, 7], 7) renvoie 1 ; recherche([4, 7, 2, 7], 9) renvoie -1.

Exercice 14 — Positions d'une valeur

Entraînement

Écrire positions(L, x) qui renvoie la liste de tous les indices où x apparaît.

def positions(L, x):
    return [i for i in range(len(L)) if L[i] == x]

# positions([1, 2, 1, 3, 1], 1) renvoie [0, 2, 4]

Compréhension parcourant les indices avec un filtre.

Exercice 15 — Prédire (différences)

Entraînement
L = [1, 2, 3, 4]
M = [L[i] + L[i+1] for i in range(len(L) - 1)]
print(M)

Pour \(i = 0, 1, 2\), on calcule \(L[i] + L[i+1]\) : \(1+2, 2+3, 3+4\), soit [3, 5, 7]. La borne len(L)-1 évite le débordement d'indice.

Exercice 16 — Tri à bulles (type concours)

Approfondissement

Compléter/écrire tri_bulles(L) qui trie la liste par ordre croissant en échangeant les éléments adjacents mal ordonnés. Dérouler sur [3, 1, 2].

def tri_bulles(L):
    n = len(L)
    for i in range(n):
        for j in range(n - 1 - i):
            if L[j] > L[j+1]:
                L[j], L[j+1] = L[j+1], L[j]
    return L

Sur [3, 1, 2] : \(i=0\) : \(3>1\) ⟹ [1, 3, 2], puis \(3>2\) ⟹ [1, 2, 3]. \(i=1\) : \(1>2\) faux. Résultat : [1, 2, 3]. Les grandes valeurs « remontent » comme des bulles.

Exercice 17 — Minimum et son indice (type concours)

Approfondissement

Sans utiliser min, écrire minimum(L) qui renvoie le couple (valeur minimale, indice de sa première occurrence).

def minimum(L):
    m, im = L[0], 0
    for i in range(1, len(L)):
        if L[i] < m:
            m, im = L[i], i
    return m, im
# minimum([5, 2, 8, 2]) renvoie (2, 1)

On garde l'inégalité stricte pour renvoyer la première occurrence du minimum.

Exercice 18 — Comptage par effectifs (type concours)

Approfondissement

Une liste ne contient que des entiers entre 0 et \(k\). Écrire effectifs(L, k) qui renvoie la liste \(E\) telle que E[v] soit le nombre d'occurrences de la valeur \(v\).

def effectifs(L, k):
    E = [0] * (k + 1)      # cases 0, 1, ..., k
    for x in L:
        E[x] = E[x] + 1    # on incrémente la case de la valeur lue
    return E
# effectifs([1, 3, 1, 0, 3, 3], 3) renvoie [1, 2, 0, 3]

Ce « comptage par cases » sert à construire un histogramme de simulation (fiche I4).

Exercice 19 — Premier dépassement de seuil (type concours)

Approfondissement

Écrire premier_depassement(L, seuil) qui renvoie le plus petit indice \(i\) tel que \(L[0] + \dots + L[i] > seuil\), ou -1 si la somme totale ne dépasse jamais le seuil.

def premier_depassement(L, seuil):
    s = 0
    for i in range(len(L)):
        s = s + L[i]
        if s > seuil:
            return i
    return -1
# premier_depassement([2, 3, 5, 4], 8) renvoie 2 (2 + 3 + 5 = 10 > 8)

Exercice 20 — Fonction mystère (type concours)

Approfondissement

Que renvoie mystere([1, 2, 3, 2, 1]) ? Et mystere([1, 2, 3]) ? Que teste cette fonction ?

def mystere(L):
    i, j = 0, len(L) - 1
    while i < j:
        if L[i] != L[j]:
            return False
        i = i + 1
        j = j - 1
    return True

Deux indices partent des extrémités et se rapprochent, comparant les éléments symétriques. Si une paire diffère, on renvoie False ; sinon True.

mystere([1, 2, 3, 2, 1]) renvoie True, mystere([1, 2, 3]) renvoie False (\(L[0]=1 \neq L[2]=3\)). La fonction teste si la liste est un palindrome.
