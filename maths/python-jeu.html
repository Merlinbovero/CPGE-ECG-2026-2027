Python — Le jeu 70 niveaux

Apprends à coder en t'amusant : 70 niveaux progressifs, du plus simple (après le cours) jusqu'au niveau concours. Tu écris du vrai code Python, il est exécuté dans ton navigateur et validé automatiquement par des tests. Débloque les niveaux un à un — ta progression est sauvegardée.

Comment jouer
  • Palier 1 — Découverte (1-19) : les bases, juste après avoir lu les fiches I1 et I2.
  • Palier 2 — Renforcement (20-49) : traduire des formules mathématiques en code (sommes, suites, binôme…).
  • Palier 3 — Concret (50-70) : de vrais problèmes, du code plus long (simulations, matrices, algorithmes).

La première exécution charge Python (Pyodide) : quelques secondes et une connexion internet, une seule fois par visite. Écris une fonction du nom demandé, clique sur « Exécuter les tests ». ⚠️ Évite les boucles infinies (elles figent la page).
