Formulaire / Mémo — toutes les formules du programme

Les formules et résultats indispensables des 17 chapitres, regroupés sur une page pour une relecture rapide avant une colle ou un DS. Chaque bloc renvoie au chapitre correspondant pour la démonstration et les exercices.

Relecture express · révisions de dernière minute

Algèbre et calcul (ch. 1 à 5)

Ch. 2 — Sommes, produits, binôme
  • \(\displaystyle\sum_{k=1}^n k = \frac{n(n+1)}{2}\), \(\displaystyle\sum_{k=1}^n k^2 = \frac{n(n+1)(2n+1)}{6}\), \(\displaystyle\sum_{k=1}^n k^3 = \left(\frac{n(n+1)}{2}\right)^2\).
  • Somme géométrique : \(\displaystyle\sum_{k=0}^n q^k = \frac{1 - q^{n+1}}{1 - q}\) (\(q \neq 1\)).
  • Binôme de Newton : \((a+b)^n = \displaystyle\sum_{k=0}^n \binom nk a^k b^{n-k}\) ; \(\binom nk = \frac{n!}{k!(n-k)!}\).
  • Somme des impairs : \(\displaystyle\sum_{k=1}^n (2k-1) = n^2\).
Ch. 4-5 — Systèmes et matrices
  • Produit : \((AB)_{ij} = \displaystyle\sum_k a_{ik}b_{kj}\) ; en général \(AB \neq BA\).
  • \(2\times2\) : \(\begin{pmatrix} a & b \\ c & d\end{pmatrix}^{-1} = \frac{1}{ad-bc}\begin{pmatrix} d & -b \\ -c & a\end{pmatrix}\) si \(ad - bc \neq 0\).
  • \((AB)^{-1} = B^{-1}A^{-1}\), \((A^{\top})^{\top} = A\), \((AB)^{\top} = B^{\top}A^{\top}\).
  • Système : pivot de Gauss ; solution unique ⟺ matrice inversible ⟺ déterminant non nul.

Analyse (ch. 6 à 8, 12)

Ch. 6 — Suites
  • Arithmétique : \(u_n = u_0 + nr\). Géométrique : \(u_n = u_0\,q^n\).
  • Arithmético-géométrique \(u_{n+1} = au_n + b\) (\(a\neq1\)) : point fixe \(\ell = \frac{b}{1-a}\), \(u_n - \ell = a^n(u_0 - \ell)\).
  • \(q^n \to 0\) si \(|q| < 1\) ; \(\to +\infty\) si \(q > 1\).
  • Convergence : monotone + bornée ; théorème des gendarmes ; si \(u_{n+1} = f(u_n)\) et \(u_n \to \ell\) avec \(f\) continue, alors \(f(\ell) = \ell\).
Ch. 7 — Limites, continuité
  • Croissances comparées : \(\frac{(\ln x)^\alpha}{x^\beta} \to 0\), \(\frac{x^\beta}{\mathrm{e}^{\gamma x}} \to 0\) (\(x \to +\infty\)).
  • \(\ln(ab) = \ln a + \ln b\), \(\mathrm{e}^{a+b} = \mathrm{e}^a\mathrm{e}^b\), \(\ln'(x) = \frac1x\), \((\mathrm{e}^x)' = \mathrm{e}^x\).
  • TVI : \(f\) continue sur \([a,b]\), \(f(a)f(b) < 0\) ⟹ un zéro dans \(]a,b[\).
Ch. 8 — Dérivation, convexité
  • \((uv)' = u'v + uv'\), \(\left(\frac uv\right)' = \frac{u'v - uv'}{v^2}\), \((f\circ g)' = g'\times(f'\circ g)\).
  • \(f' > 0\) ⟹ \(f\) croissante ; extremum en \(x_0\) intérieur ⟹ \(f'(x_0) = 0\).
  • \(f\) convexe ⟺ \(f'' \geqslant 0\) ⟺ courbe au-dessus de ses tangentes ; point d'inflexion : \(f''\) change de signe.
Ch. 12 — Intégration
  • \(\int_a^b f = [F]_a^b = F(b) - F(a)\) ; \(\int u'u^n = \frac{u^{n+1}}{n+1}\), \(\int\frac{u'}{u} = \ln|u|\), \(\int u'\mathrm{e}^u = \mathrm{e}^u\).
  • IPP : \(\int_a^b u'v = [uv]_a^b - \int_a^b uv'\) (\(u,v\) de classe \(\mathscr{C}^1\)).
  • Somme de Riemann : \(\frac1n\sum_{k=1}^n f(\frac kn) \to \int_0^1 f\).

Probabilités (ch. 10, 11, 14, 15)

Ch. 10 — Probabilités finies
  • \(P(A\cup B) = P(A) + P(B) - P(A\cap B)\) ; \(P(\bar A) = 1 - P(A)\).
  • Conditionnelle : \(P_B(A) = \frac{P(A\cap B)}{P(B)}\) ; composées : \(P(A\cap B) = P(A)P_A(B)\).
  • Probabilités totales : \(P(A) = \sum_i P(B_i)P_{B_i}(A)\) ; Bayes : \(P_A(B_i) = \frac{P(B_i)P_{B_i}(A)}{P(A)}\).
  • Indépendants : \(P(A\cap B) = P(A)P(B)\) (≠ incompatibles).
Ch. 11 — Variables aléatoires, lois finies
  • \(E(X) = \sum x_i P(X=x_i)\), \(E(aX+b) = aE(X)+b\), transfert \(E(g(X)) = \sum g(x_i)P(X=x_i)\).
  • \(V(X) = E(X^2) - E(X)^2\), \(V(aX+b) = a^2V(X)\), \(\sigma = \sqrt V\).
  • Uniforme \(\mathcal U(\llbracket1,n\rrbracket)\) : \(E = \frac{n+1}2\), \(V = \frac{n^2-1}{12}\).
  • Bernoulli \(\mathscr B(p)\) : \(E = p\), \(V = p(1-p)\). Binomiale \(\mathscr B(n,p)\) : \(P(X=k) = \binom nk p^k(1-p)^{n-k}\), \(E = np\), \(V = np(1-p)\).
Ch. 14 — Lois géométrique et de Poisson
  • Géométrique \(\mathscr G(p)\) : \(P(X=k) = (1-p)^{k-1}p\) (\(k\geqslant1\)), \(E = \frac1p\), \(V = \frac{1-p}{p^2}\), \(P(X>n) = (1-p)^n\), sans mémoire.
  • Poisson \(\mathscr P(\lambda)\) : \(P(X=k) = \mathrm{e}^{-\lambda}\frac{\lambda^k}{k!}\), \(E = V = \lambda\).
  • Approximation : \(\mathscr B(n,p) \approx \mathscr P(np)\) (\(n\) grand, \(p\) petit).
Ch. 15 — Couples de v.a.
  • \(E(X+Y) = E(X) + E(Y)\) (toujours) ; \(E(XY) = E(X)E(Y)\) si indépendance.
  • \(\mathrm{Cov}(X,Y) = E(XY) - E(X)E(Y)\) ; \(V(X+Y) = V(X) + V(Y) + 2\mathrm{Cov}(X,Y)\).
  • Indépendance ⟹ \(\mathrm{Cov} = 0\) (réciproque fausse). Stabilité : \(\mathscr B(n,p)+\mathscr B(m,p)=\mathscr B(n+m,p)\), \(\mathscr P(\lambda)+\mathscr P(\mu)=\mathscr P(\lambda+\mu)\).

Séries, graphes, statistiques (ch. 13, 16, 17)

Ch. 13 — Séries
  • Nécessaire : \(u_n \to 0\) (non suffisant). Géométrique : \(\sum_{n\geqslant0} q^n = \frac1{1-q}\) si \(|q|<1\).
  • Dérivées : \(\sum n q^{n-1} = \frac1{(1-q)^2}\), \(\sum n q^n = \frac{q}{(1-q)^2}\).
  • Riemann : \(\sum\frac1{n^\alpha}\) converge ⟺ \(\alpha > 1\). Exponentielle : \(\sum\frac{x^n}{n!} = \mathrm{e}^x\).
Ch. 16 — Graphes
  • Poignées de main : \(\sum_s d(s) = 2\,|\text{arêtes}|\).
  • \((A^k)_{ij}\) = nombre de chemins de longueur \(k\) de \(s_i\) à \(s_j\) ; \((A^2)_{ii} = d(s_i)\).
Ch. 17 — Statistiques
  • \(s^2 = \frac1n\sum x_i^2 - \bar x^2\) ; \(s_{xy} = \frac1n\sum x_iy_i - \bar x\,\bar y\) ; \(r = \frac{s_{xy}}{s_x s_y} \in [-1,1]\).
  • Moindres carrés (\(y\) en \(x\)) : \(a = \frac{s_{xy}}{s_x^2}\), \(b = \bar y - a\bar x\) ; passe par \((\bar x, \bar y)\).
