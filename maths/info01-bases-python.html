Informatique I1. Bases du langage Python

L'informatique fait partie intégrante de l'épreuve de maths appliquées : chaque sujet contient des questions Python (compléter un programme, prédire une sortie). Cette fiche couvre le socle : variables, types, conditions, boucles, fonctions.

Objectifs de la fiche (programme officiel)

  • Écrire des conditions (if/elif/else) et respecter l'indentation comme syntaxe.
  • Maîtriser les boucles for (avec range) et while (algorithmes de seuil).
  • Définir des fonctions et distinguer return de print.
  • Savoir prédire une sortie, compléter et déboguer un programme — les trois formats de questions au concours.

1. Variables et types

Une variable se crée par affectation avec = (à ne pas confondre avec le test d'égalité ==). Les types de base :

n = 7           # int : entier
x = 3.14        # float : flottant (nombre à virgule)
s = "bonjour"   # str : chaîne de caractères
b = True        # bool : booléen (True ou False)
print(type(n))  # affiche : <class 'int'>

Conversions : int("5") donne 5, float(3) donne 3.0, str(12) donne "12".

3. Conditions : if / elif / else

note = 13
if note >= 16:
    mention = "très bien"
elif note >= 12:
    mention = "assez bien"       # ce bloc est exécuté
else:
    mention = "sans mention"
print(mention)                    # affiche : assez bien
L'indentation est la syntaxe

En Python, les blocs sont délimités par l'indentation (4 espaces par convention) après le :. Une indentation incorrecte change le sens du programme ou provoque une erreur — c'est le point le plus vérifié dans les questions « compléter le code ».

4. Boucles : for et while

Boucle for : nombre d'itérations connu. range(n) parcourt \(0, 1, \dots, n-1\) ; range(a, b) parcourt \(a, \dots, b-1\) (borne droite exclue !) ; range(a, b, p) avance de \(p\) en \(p\).

S = 0
for k in range(1, 11):   # k = 1, 2, ..., 10
    S = S + k
print(S)                  # affiche : 55  (somme des 10 premiers entiers)

Boucle while : on itère tant qu'une condition est vraie (nombre d'itérations inconnu a priori — algorithmes de seuil, voir fiche I5).

u = 1000
n = 0
while u > 500:
    u = u * 0.9
    n = n + 1
print(n)   # affiche : 7  (car 1000 * 0.9**7 = 478.3 < 500 < 1000 * 0.9**6 = 531.4)

5. Fonctions

def f(x):
    return x**2 + 1

def somme_carres(n):
    """Renvoie 1² + 2² + ... + n²."""
    S = 0
    for k in range(1, n + 1):
        S += k**2
    return S

print(f(3))              # affiche : 10
print(somme_carres(4))   # affiche : 30
Méthode — return vs print

return renvoie une valeur utilisable dans la suite du programme (et interrompt la fonction) ; print se contente d'afficher. Aux concours, une fonction doit presque toujours return son résultat. Un return placé dans une boucle sort de la fonction dès la première itération — erreur classique.

6. Erreurs classiques

  • range(n) s'arrête à \(n - 1\) : pour sommer jusqu'à \(n\), écrire range(n + 1) ou range(1, n + 1).
  • Oublier d'initialiser l'accumulateur (S = 0, produit = 1) avant la boucle.
  • Confondre = (affectation) et == (comparaison).
  • Boucle while qui ne se termine pas (condition jamais fausse) : vérifier que la variable de contrôle évolue.
  • Division : / renvoie un float même entre entiers ; pour un indice, utiliser //.
Fiche de révision condensée
  • Types : int, float (/ donne un float), str, bool.
  • Opérateurs : // quotient, % reste, ** puissance ; n % 2 == 0 teste la parité.
  • Condition : if … : / elif … : / else :, blocs délimités par l'indentation.
  • for : range(a, b, p) parcourt \(a, a+p, \dots\) sans atteindre \(b\) (borne exclue).
  • while : itère tant que la condition est vraie ; s'assurer que la variable de contrôle évolue.
  • Fonction : def f(x): … return … ; return renvoie et sort, print affiche.
  • Accumulateur : initialiser (S = 0, p = 1) avant la boucle ; return après la boucle.
  • Échange : a, b = b, a (affectation simultanée).

Exercices corrigés

Exercice 1 — Prédire la sortie

Application directe

Que affichent les programmes suivants ?

# Programme A
x = 5
x = x + 2
x = x * x
print(x)

# Programme B
s = 0
for k in range(4):
    s = s + 2*k
print(s)

# Programme C
a, b = 17, 5
print(a // b, a % b)

A : x vaut 5, puis 7, puis 49. Affiche 49.

B : \(k\) prend les valeurs 0, 1, 2, 3 ; \(s = 0 + 0 + 2 + 4 + 6 = 12\). Affiche 12.

C : \(17 = 3 \times 5 + 2\) : affiche 3 2.

Exercice 2 — Écrire une fonction simple

Application directe

Écrire une fonction factorielle(n) qui renvoie \(n!\) (avec une boucle for), puis une fonction est_pair(n) qui renvoie True si \(n\) est pair.

def factorielle(n):
    p = 1
    for k in range(1, n + 1):
        p = p * k
    return p          # factorielle(5) renvoie 120 ; factorielle(0) renvoie 1

def est_pair(n):
    return n % 2 == 0    # le test renvoie déjà un booléen

Noter l'initialisation à 1 (produit vide) : factorielle(0) renvoie bien \(0! = 1\).

Exercice 3 — Boucle while

Entraînement

Un capital de 2 000 € est placé à 3 % par an. Écrire un programme qui calcule au bout de combien d'années le capital dépasse 3 000 €, et donner la valeur affichée.

C = 2000
n = 0
while C <= 3000:
    C = C * 1.03
    n = n + 1
print(n)

Il faut \(1{,}03^n > 1{,}5\), soit \(n > \frac{\ln 1{,}5}{\ln 1{,}03} \approx 13{,}7\) : le programme affiche 14.

Exercice 4 — Compléter un programme (format concours)

Entraînement

Compléter les pointillés pour que u(n) renvoie le terme \(u_n\) de la suite définie par \(u_0 = 3\) et \(u_{k+1} = 2u_k - 1\) :

def u(n):
    x = ......
    for k in range(......):
        x = ......
    return x
def u(n):
    x = 3                    # u_0
    for k in range(n):       # n itérations : de u_0 à u_n
        x = 2*x - 1
    return x

Contrôle : u(0) renvoie 3 (aucune itération) ; u(2) renvoie \(2(2 \times 3 - 1) - 1 = 9\). (Au passage, \(u_n = 2^{n+1} + 1\) : voir chapitre 6.)

Exercice 5 — Trace d'exécution (type concours)

Approfondissement

Que renvoie mystere(36, 24) ? Que calcule cette fonction en général ?

def mystere(a, b):
    while b != 0:
        a, b = b, a % b
    return a

Trace : \((a, b) = (36, 24) \to (24, 12) \to (12, 0)\) : la fonction renvoie 12.

C'est l'algorithme d'Euclide : à chaque étape, on remplace \((a, b)\) par \((b, a \bmod b)\), ce qui conserve l'ensemble des diviseurs communs ; quand \(b = 0\), \(a\) est le PGCD des deux entiers de départ. \(\mathrm{pgcd}(36, 24) = 12\) ✓.

La syntaxe a, b = b, a % b effectue les deux affectations simultanément (avec les anciennes valeurs) — sans variable temporaire.

Exercice 6 — Débogage (type concours)

Approfondissement

Le programme suivant est censé calculer \(\sum_{k=1}^{n} \frac1k\), mais contient trois erreurs. Les trouver et les corriger.

def harmonique(n):
    S = 1
    for k in range(1, n):
        S = S + 1/k
        return S
  1. S = 1 : l'accumulateur doit démarrer à 0 (sinon le terme \(k=1\) est compté deux fois… en fait ici il fausse tout le calcul).
  2. range(1, n) s'arrête à \(n-1\) : il faut range(1, n + 1).
  3. Le return est dans la boucle : la fonction sort dès la première itération. Il faut le désindenter (aligné avec for).
def harmonique(n):
    S = 0
    for k in range(1, n + 1):
        S = S + 1/k
    return S      # harmonique(3) renvoie 1 + 0.5 + 0.333... = 1.8333...

Exercice 7 — Conditions et modulo

Application directe

Que affichent ces programmes ?

# Programme A
x = 10
if x % 3 == 0:
    print("A")
elif x % 2 == 0:
    print("B")
else:
    print("C")

# Programme B
for i in range(2, 9, 2):
    print(i)

A : \(10 \bmod 3 = 1 \neq 0\), puis \(10 \bmod 2 = 0\) : le bloc elif s'exécute, affiche B.

B : range(2, 9, 2) parcourt \(2, 4, 6, 8\) (9 exclu) : affiche 2, 4, 6, 8 (une par ligne).

Exercice 8 — Maximum de deux nombres

Application directe

Écrire une fonction maximum(a, b) qui renvoie le plus grand des deux nombres (sans utiliser max).

def maximum(a, b):
    if a >= b:
        return a
    else:
        return b        # maximum(3, 7) renvoie 7

Exercice 9 — Test de multiple

Application directe

Écrire une fonction est_multiple(n, d) qui renvoie True si \(n\) est un multiple de \(d\).

def est_multiple(n, d):
    return n % d == 0    # est_multiple(15, 5) renvoie True ; est_multiple(15, 4) renvoie False

Le test n % d == 0 renvoie déjà un booléen : pas besoin de if.

Exercice 10 — Produit dans une boucle

Application directe

Que affiche ce programme ?

s = 1
for k in range(1, 5):
    s = s * k
print(s)

\(k\) prend les valeurs \(1, 2, 3, 4\), et \(s = 1\times1\times2\times3\times4 = 24\) : affiche 24 (c'est \(4!\)).

Exercice 11 — Somme des impairs

Entraînement

Écrire une fonction somme_impairs(n) qui renvoie \(1 + 3 + 5 + \dots + (2n-1)\). Que vaut somme_impairs(4) ? Quelle formule reconnaît-on ?

def somme_impairs(n):
    S = 0
    for k in range(1, n + 1):
        S = S + (2*k - 1)
    return S

somme_impairs(4) \(= 1 + 3 + 5 + 7 = 16 = 4^2\). En effet la somme des \(n\) premiers impairs vaut \(n^2\) (chapitre 2).

Exercice 12 — Seuil avec while

Entraînement

Que affiche ce programme, et que calcule-t-il ?

n = 0
p = 1
while p <= 1000:
    p = p * 2
    n = n + 1
print(n)

À chaque tour, \(p\) double : après \(n\) tours, \(p = 2^n\). La boucle s'arrête dès que \(p > 1000\), c'est-à-dire \(2^n > 1000\). Comme \(2^9 = 512 \leqslant 1000 < 1024 = 2^{10}\), on sort avec \(n = 10\) : affiche 10 (le plus petit \(n\) tel que \(2^n > 1000\)).

Exercice 13 — Compléter une suite récurrente

Entraînement

Compléter u(n) pour la suite \(u_0 = 2\), \(u_{k+1} = 3u_k + 1\) :

def u(n):
    x = ......
    for k in range(......):
        x = ......
    return x
def u(n):
    x = 2                # u_0
    for k in range(n):   # n itérations
        x = 3*x + 1
    return x

Contrôle : u(0) renvoie 2 ; u(1) renvoie 7 ; u(2) renvoie 22.

Exercice 14 — Compter les diviseurs

Entraînement

Écrire une fonction nb_diviseurs(n) qui renvoie le nombre de diviseurs positifs de \(n\). Que vaut nb_diviseurs(12) ?

def nb_diviseurs(n):
    c = 0
    for d in range(1, n + 1):
        if n % d == 0:
            c = c + 1
    return c

nb_diviseurs(12) compte \(1, 2, 3, 4, 6, 12\) : renvoie 6.

Exercice 15 — Suite de Collatz (type concours)

Entraînement

Que calcule ce programme ? Donner la valeur affichée pour \(n = 100\).

n = 100
c = 0
while n > 1:
    if n % 2 == 0:
        n = n // 2
    else:
        n = 3*n + 1
    c = c + 1
print(c)

Le programme applique la règle de Syracuse (Collatz) : tant que \(n > 1\), on divise par 2 si pair, sinon on fait \(3n+1\) ; c compte les étapes jusqu'à atteindre 1.

Pour \(n = 100\) : \(100 \to 50 \to 25 \to 76 \to 38 \to 19 \to 58 \to 29 \to 88 \to 44 \to 22 \to 11 \to 34 \to 17 \to 52 \to 26 \to 13 \to 40 \to 20 \to 10 \to 5 \to 16 \to 8 \to 4 \to 2 \to 1\), soit 25 étapes : affiche 25.

Exercice 16 — Trace d'une suite de Fibonacci (type concours)

Approfondissement

Que renvoie fib(6) ? Détailler l'évolution du couple (a, b).

def fib(n):
    a, b = 0, 1
    for k in range(n):
        a, b = b, a + b
    return a

Le couple (a, b) évolue (affectation simultanée) : \((0,1) \to (1,1) \to (1,2) \to (2,3) \to (3,5) \to (5,8) \to (8,13)\) après 6 tours.

La fonction renvoie \(a = 8\), le 6e terme de la suite de Fibonacci \(0, 1, 1, 2, 3, 5, 8, \dots\)

Exercice 17 — Débogage d'un produit (type concours)

Approfondissement

Cette fonction devrait renvoyer \(n! = 1\times2\times\dots\times n\), mais contient deux erreurs. Les corriger.

def produit(n):
    p = 0
    for k in range(1, n):
        p = p * k
    return p
  1. p = 0 : un produit doit s'initialiser à 1 (sinon tout reste nul).
  2. range(1, n) s'arrête à \(n-1\) : il faut range(1, n + 1) pour inclure \(n\).
def produit(n):
    p = 1
    for k in range(1, n + 1):
        p = p * k
    return p          # produit(5) renvoie 120

Exercice 18 — Test de primalité (type concours)

Approfondissement

Écrire une fonction est_premier(n) qui renvoie True si \(n\) est premier. Expliquer pourquoi le return False peut se placer dans la boucle.

def est_premier(n):
    if n < 2:
        return False
    for d in range(2, n):
        if n % d == 0:
            return False    # un diviseur trouvé : inutile de continuer
    return True             # aucun diviseur : n est premier

Dès qu'un diviseur \(d\) est trouvé, \(n\) n'est pas premier : le return False dans la boucle interrompt aussitôt la fonction (c'est ici un avantage). Le return True final n'est atteint que si la boucle s'est terminée sans diviseur.

Optimisation classique : s'arrêter à \(\sqrt n\) avec range(2, int(n**0.5) + 1).

Exercice 19 — Somme des chiffres (type concours)

Approfondissement

Que renvoie somme_chiffres(2024) ? Expliquer le rôle de % 10 et // 10.

def somme_chiffres(n):
    s = 0
    while n > 0:
        s = s + n % 10
        n = n // 10
    return s

n % 10 extrait le chiffre des unités ; n // 10 supprime ce chiffre. On additionne donc les chiffres un à un.

Trace pour \(2024\) : \(s = 4\) (\(n=202\)), puis \(6\) (\(n=20\)), puis \(6\) (\(n=2\)), puis \(8\) (\(n=0\), fin). Renvoie 8 (soit \(2+0+2+4\)).

Exercice 20 — Fonction mystère (type concours)

Approfondissement

Que renvoie mystere(2, 5) ? Que calcule cette fonction en général ?

def mystere(x, n):
    r = 1
    while n > 0:
        if n % 2 == 1:
            r = r * x
        x = x * x
        n = n // 2
    return r

Trace pour \((x, n) = (2, 5)\) : \(r=1, x=2, n=5\) (impair) \(\to r=2, x=4, n=2\) ; \(n=2\) (pair) \(\to x=16, n=1\) ; \(n=1\) (impair) \(\to r=32, x=256, n=0\). Renvoie 32.

C'est l'exponentiation rapide : la fonction calcule \(x^n\) (ici \(2^5 = 32\)) en \(\mathcal{O}(\log n)\) multiplications, en exploitant l'écriture binaire de \(n\).
