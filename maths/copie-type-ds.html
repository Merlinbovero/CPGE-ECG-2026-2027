Copie-type : un devoir de maths entièrement rédigé

On sait ce qu'il faut faire (le cours) ; il faut aussi voir à quoi ressemble une copie qui obtient les points. Voici un problème de niveau concours (type EDHEC / Ecricome), rédigé comme il doit l'être : chaque affirmation justifiée, chaque théorème cité avec ses hypothèses. La colonne de droite (les notes en marge) explique pourquoi on rédige ainsi — c'est là qu'est la vraie leçon.

Comment utiliser cette page
  1. D'abord seul : traite le sujet ci-dessous sur une copie, chronométré (≈ 1 h 15), avant de lire quoi que ce soit.
  2. Ensuite compare ta rédaction à la copie-type : non pas « ai-je trouvé le résultat ? » mais « ai-je justifié comme cela ? ».
  3. Enfin, relis uniquement les notes en marge : ce sont les réflexes de rédaction qui font gagner (ou perdre) les points.

1. L'énoncé

Sujet — durée conseillée 1 h 15

Partie A. On considère la fonction \(g\) définie sur \([0,+\infty[\) par \(g(x) = 1 - e^{-x}\), et la suite \((u_n)_{n\ge 0}\) définie par \(u_0 = 1\) et, pour tout \(n\in\mathbb N\), \(u_{n+1} = g(u_n)\).

  1. Étudier les variations et la convexité de \(g\) sur \([0,+\infty[\).
  2. Montrer que pour tout \(x \ge 0\), \(0 \le g(x) \le x\).
  3. En déduire que \((u_n)\) est bien définie, à valeurs dans \([0,1]\), décroissante, puis qu'elle converge et déterminer sa limite.
  4. Pour \(n\in\mathbb N\), on pose \(v_n = \dfrac{1}{u_n}\). Montrer que \(v_{n+1} - v_n \xrightarrow[n\to+\infty]{} \dfrac12\), puis en déduire un équivalent simple de \(u_n\) quand \(n\to+\infty\).

Partie B. On lance indéfiniment une pièce équilibrée. On note \(X\) le rang d'apparition du premier Pile.

  1. Reconnaître la loi de \(X\). Donner \(P(X = k)\) pour \(k\in\mathbb N^*\), l'espérance et la variance de \(X\).
  2. Calculer \(P(X \ge n)\) pour \(n\in\mathbb N^*\).
  3. Calculer la probabilité que \(X\) soit pair.
  4. Écrire une fonction Python simule() qui simule \(X\) et renvoie sa valeur.

2. Corrigé rédigé — Partie A

Partie A — Étude de la suite \((u_n)\)

1. La fonction \(g : x \mapsto 1 - e^{-x}\) est de classe \(\mathcal C^\infty\) sur \([0,+\infty[\) comme composée de fonctions usuelles. Pour tout \(x \ge 0\) : \[ g'(x) = e^{-x} > 0, \qquad g''(x) = -e^{-x} < 0. \] Donc \(g\) est strictement croissante et concave sur \([0,+\infty[\).
Réflexe : on annonce la régularité (\(\mathcal C^\infty\)) avant de dériver — cela légitime le calcul. Signe de \(g'\) puis de \(g''\) : deux points faciles, ne jamais les sauter.
2. Soit \(x \ge 0\). D'une part \(e^{-x} \le 1\) donc \(g(x) = 1 - e^{-x} \ge 0\). D'autre part, posons \(h(x) = x - g(x) = x - 1 + e^{-x}\). Alors \(h(0) = 0\) et \(h'(x) = 1 - e^{-x} \ge 0\) pour \(x \ge 0\), donc \(h\) est croissante sur \([0,+\infty[\) : pour tout \(x\ge 0\), \(h(x) \ge h(0) = 0\), c'est-à-dire \(g(x) \le x\). Finalement \(\boxed{0 \le g(x) \le x}\) pour tout \(x \ge 0\).
Méthode-clé : pour comparer deux fonctions, on étudie leur différence. On exhibe une valeur où elle s'annule (ici \(0\)) puis le signe de la dérivée : la monotonie conclut. À réutiliser sans cesse.
3. Montrons par récurrence que pour tout \(n\in\mathbb N\), \(u_n \in [0,1]\).
Initialisation : \(u_0 = 1 \in [0,1]\). Hérédité : si \(u_n \in [0,1]\), alors \(u_n \ge 0\) donc, par la question 2, \(0 \le u_{n+1} = g(u_n) \le u_n \le 1\). Donc \(u_{n+1}\in[0,1]\). La suite est donc bien définie et à valeurs dans \([0,1]\).
De plus l'inégalité \(u_{n+1} = g(u_n) \le u_n\) (question 2, licite car \(u_n \ge 0\)) montre que \((u_n)\) est décroissante. Décroissante et minorée par \(0\), elle converge vers une limite \(\ell \in [0,1]\).
\(g\) étant continue et \(u_{n+1} = g(u_n)\), la limite vérifie \(\ell = g(\ell)\), soit \(h(\ell) = 0\). Or \(h\) est strictement croissante sur \(]0,+\infty[\) (car \(h'(x) = 1 - e^{-x} > 0\) pour \(x>0\)) et \(h(0)=0\) : \(0\) est donc l'unique solution. Ainsi \(\boxed{\displaystyle\lim_{n\to+\infty} u_n = 0}\).
Le trio gagnant pour une suite récurrente : (i) stabilité de l'intervalle par récurrence ; (ii) monotonie ; (iii) théorème de la limite monotone puis point fixe par continuité. Ne jamais écrire « \(\ell = g(\ell)\) » sans avoir dit que \(g\) est continue.

Piège évité : on justifie l'unicité du point fixe (sinon la limite n'est pas déterminée).
4. Comme \(u_n \to 0\) avec \(u_n > 0\) pour tout \(n\) (une récurrence immédiate donne \(u_n>0\), car \(g(x)>0\) dès que \(x>0\)), la suite \(v_n = 1/u_n\) est bien définie. On écrit : \[ v_{n+1} - v_n = \frac{1}{u_{n+1}} - \frac{1}{u_n} = \frac{1}{g(u_n)} - \frac{1}{u_n}. \] Posons \(\varphi(x) = \dfrac{1}{g(x)} - \dfrac1x\) pour \(x>0\). Quand \(x \to 0^+\), le développement limité \(e^{-x} = 1 - x + \dfrac{x^2}{2} + o(x^2)\) donne \(g(x) = x - \dfrac{x^2}{2} + o(x^2) = x\left(1 - \dfrac x2 + o(x)\right)\), d'où \[ \frac{1}{g(x)} = \frac1x\cdot\frac{1}{1 - \frac x2 + o(x)} = \frac1x\left(1 + \frac x2 + o(x)\right) = \frac1x + \frac12 + o(1). \] Donc \(\varphi(x) = \dfrac12 + o(1) \xrightarrow[x\to 0^+]{} \dfrac12\). Comme \(u_n \to 0^+\), on obtient \(v_{n+1} - v_n = \varphi(u_n) \to \dfrac12\).
Par le théorème de Cesàro, \(\dfrac{v_n}{n} = \dfrac1n\sum_{k=0}^{n-1}(v_{k+1}-v_k) + \dfrac{v_0}{n} \to \dfrac12\), donc \(v_n \sim \dfrac n2\), et enfin \[ \boxed{\,u_n \sim \dfrac{2}{n}\ \text{quand } n\to+\infty.} \]
Technique de concours par excellence : face à une suite \(u_{n+1}=u_n - a\,u_n^2 + o(u_n^2)\), on passe à \(1/u_n\) pour « linéariser ». Le DL de \(e^{-x}\) doit être su par cœur.

Le passage « \(v_{n+1}-v_n \to \ell\) donc \(v_n/n \to \ell\) » est exactement le lemme de Cesàro — le nommer rapporte des points.

3. Corrigé rédigé — Partie B

Partie B — La variable aléatoire \(X\)

1. On répète, de façon indépendante, une même épreuve de Bernoulli (« obtenir Pile ») de paramètre \(p = \tfrac12\), et \(X\) compte le rang du premier succès : \(X\) suit donc la loi géométrique de paramètre \(p=\tfrac12\), notée \(X \hookrightarrow \mathcal G\!\left(\tfrac12\right)\). Pour \(k\in\mathbb N^*\), \[ P(X = k) = (1-p)^{k-1}p = \left(\tfrac12\right)^{k-1}\cdot\tfrac12 = \left(\tfrac12\right)^{k}. \] D'après le cours, \(E(X) = \dfrac1p = 2\) et \(V(X) = \dfrac{1-p}{p^2} = \dfrac{1/2}{1/4} = 2\).
Identifier la loi avant tout calcul : « répétitions indépendantes + rang du premier succès » ⇒ loi géométrique. On cite alors \(E\) et \(V\) du cours plutôt que de les recalculer (sauf si l'énoncé l'exige).
2. L'événement \((X \ge n)\) signifie « les \(n-1\) premiers lancers donnent Face », d'où, par indépendance, \[ P(X \ge n) = \left(\tfrac12\right)^{n-1}, \qquad n\in\mathbb N^*. \] (Contrôle : on retrouve bien \(P(X\ge 1) = 1\).\()\)
Deux voies possibles : l'interprétation directe (ci-contre) ou la somme \(\sum_{k\ge n}(1/2)^k\). La première est plus sûre et plus rapide. Le petit contrôle de cohérence en fin de calcul rassure le correcteur (et soi-même).
3. Le système \(\big((X=k)\big)_{k\ge 1}\) étant un système complet d'événements de somme \(1\), \[ P(X\ \text{pair}) = \sum_{j=1}^{+\infty} P(X = 2j) = \sum_{j=1}^{+\infty}\left(\tfrac12\right)^{2j} = \sum_{j=1}^{+\infty}\left(\tfrac14\right)^{j}. \] C'est une série géométrique de raison \(\tfrac14 \in\,]{-1},1[\), convergente, de somme \(\dfrac{1/4}{1 - 1/4} = \dfrac13\). Donc \(\boxed{P(X\ \text{pair}) = \dfrac13}\).
Rigueur exigée : on justifie la convergence (raison dans \(]{-1},1[\)) avant d'appliquer \(\sum_{j\ge1} q^j = \frac{q}{1-q}\). Attention à l'indice de départ (\(j=1\), pas \(0\)) : c'est \(\frac{q}{1-q}\), non \(\frac{1}{1-q}\).
4. On simule les lancers jusqu'au premier Pile en comptant le rang : 
import random

def simule():
    n = 1
    while random.random() >= 0.5:   # tant qu'on tire Face
        n = n + 1
    return n                          # rang du premier Pile
La boucle s'arrête au premier tirage \(< 0{,}5\) (« Pile »), et n contient alors le rang cherché.
Cohérence maths ↔ code : la variable n joue exactement le rôle du rang \(X\). Un while non borné convient ici car l'arrêt est presque sûr. On commente le code : le correcteur doit lire l'intention.

4. Ce que voit le correcteur

Barème-type et points de rédaction
  • Les points « gratuits » (signe de \(g'\), \(g''\), reconnaissance de la loi, \(E\) et \(V\) cités) représentent souvent 30 à 40 % de la note. Les perdre par précipitation est la première cause de copies moyennes.
  • Une récurrence se rédige toujours en trois temps nommés (initialisation / hérédité / conclusion). Une hérédité qui utilise une hypothèse non vérifiée (ici \(u_n\ge 0\)) est sanctionnée.
  • Le point fixe : pas de \(\ell = g(\ell)\) sans « \(g\) continue », pas de limite sans unicité du point fixe.
  • Une somme infinie n'est jamais calculée sans un mot sur sa convergence.
  • Encadrer les résultats finaux : le correcteur les trouve d'un coup d'œil.
⚠️ Les fautes qui coûtent le plus

Écrire « la suite converge » sans justifier (monotone + bornée) ; confondre \(\sum_{k\ge 0}\) et \(\sum_{k\ge 1}\) dans une géométrique ; « passer à la limite » dans \(u_{n+1}=g(u_n)\) sans continuité ; donner un équivalent sans passer par \(1/u_n\). Chacune est un réflexe à automatiser.
